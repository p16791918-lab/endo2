## 1교시: 부신호르몬 생리 (권상모 교수님)

> **⚠️ 주의**: 섹션 제목은 "부신호르몬 생리"이나 실제 강의 내용은 **내분비서론 및 뇌하수체호르몬 생리** 전반을 다룸. 1교시(내분비서론) + 2교시(뇌하수체호르몬 생리) 내용이 하나의 섹션에 통합되어 있음.

---

### 핵심 개념

#### 1. 호르몬의 정의와 신호전달 방식
- **Classical hormone 정의 (1902)**: ①화학물질 ②특정 기관에서 생산 ③소량이 혈액을 통해 ④먼 기관으로 운반되어 작용
- **신호전달 방식 4가지**: paracrine (조직 내 세포 간) / autocrine (동일 세포로 되돌아옴) / intracrine (세포 내부) / neuroendocrine (neurosecretory neuron에 의한 조절)

#### 2. 호르몬 종류별 특성 (핵심 비교표)

| 항목 | Peptide | Catecholamines | Thyroid Hormone | Steroids |
|---|---|---|---|---|
| **용해성** | Hydrophilic | Hydrophilic | Lipophilic | Lipophilic |
| **합성** | ER 리보솜 → Golgi | Cytosol (tyrosine 유래) | Colloid 내 | Cholesterol → 효소반응 |
| **저장** | Secretory granule | Granule | Colloid | 저장 불가 (lipid soluble) |
| **분비** | Exocytosis | Exocytosis | Endocytosis of colloid | Simple diffusion |
| **Receptor 위치** | Cell surface | Cell surface | **세포 내부** | **세포 내부** |
| **작용기전** | Second messenger | Second messenger | 특정 gene 발현 → 새 단백질 합성 | DNA 직접 결합 → gene 발현 |
| **대표 예시** | Vasopressin, Insulin | — | T3, T4 | Cortisol, Vitamin D |

#### 3. Amine 호르몬 전구체
| 전구체 | 생성 호르몬 |
|---|---|
| **Tyrosine** | Dopamine, Norepinephrine, Epinephrine, Thyroid hormone (T3/T4) |
| **Tryptophan** | Serotonin, Melatonin |
| **Glutamic acid** | Histamine |

#### 4. Steroid 호르몬 합성 핵심
- 모든 steroid hormone은 **cholesterol**에서 유래
- 미토콘드리아와 ER에서 효소 반응으로 전환
- **Rate-limiting step**: free cholesterol이 cytoplasm → mitochondria 이동
- **StAR 단백질**: 이 rate-limiting step을 조절하는 핵심 단백질
- 저장 형태: cholesterol 그 자체만이 세포 내 저장 형태
- 종류: Glucocorticoids (cortisol) / Mineralocorticoids (aldosterone) / Androgens / Estrogens / Progestogens

#### 5. 호르몬 운반
- **Hydrophilic hormone**: free form으로 혈액 내 순환 (분해 빠름)
- **Lipophilic hormone**: carrier protein(binding globulin)에 결합 → 반감기 증가, inactive 상태
  - Corticosteroid binding globulin → cortisol 운반
  - Sex steroid binding globulin → testosterone, estradiol 운반
  - 일반: albumin, prealbumin
- **오직 free type만 active**하며, 침에는 free type만 존재
- Target cell 수용체 결합력 > binding globulin 결합력 → target cell에서 분리

#### 6. 호르몬 작용 기전 4가지 (세부)

1. **Gated ion channel**: ligand 결합 → ion channel 개폐 → 이온 유입 (속도 빠름, 신경전달물질·catecholamine)
2. **G-Protein type (Serpentine receptor)**:
   - 비활성: αβγ + GDP 결합
   - 활성화: receptor-G protein 상호작용 → α-GTP / βγ 분리
   - α가 **Adenylyl cyclase** 활성화 → ATP → cAMP → PKA 활성화
   - α가 **PLC** 활성화 → PIP2 → **IP3 + DAG** 분리 → IP3: ER에서 Ca²⁺ 방출 / DAG: PKC 활성화
   - GTP → GDP 전환 시 활성 감소
3. **Receptor enzyme (Enzyme-linked receptor)**:
   - Receptor Tyrosine Kinase (RTK): 성장인자 결합 → homodimer 형성 → 내부 catalytic domain 인산화
   - 하위 신호: Grb2→Ras/Raf→MEK→ERK→NF-κB, COX-2 / PLC-γ→IP3+DAG / PI3K→BAD 인산화→apoptosis 억제
   - 대상: EGF, IGF-1, NGF, PDGF, FGF, VEGF receptor
4. **Steroid receptor (Intracellular receptor)**:
   - 지용성 호르몬이 carrier protein 분리 후 세포 내 진입
   - Nuclear receptor superfamily: hormone binding domain + **DNA binding domain (HRE)** 두 가지 domain
   - 핵 내로 이동 → HRE에 결합 → Transcription 조절 → 새 단백질 합성
   - 대상: Testosterone, Estradiol, Progesterone, Cortisol, Aldosterone, T3/T4, Vitamin D3

#### 7. 내분비계 질환

**Hyposecretion vs Hypersecretion 원인**:

| Hyposecretion | Hypersecretion |
|---|---|
| 내분비샘 자체 문제 | 내분비샘에서 과다 생산 (암 등) |
| 호르몬 제거 속도 증가 | Plasma protein binding 감소 → 과활성화 |
| Target cell receptor 부재 | 제거/불활성화 속도 저하 |
| 내부 신호 enzyme 돌연변이 | Inactivation & excretion 속도 저하 |

- **Primary hyposecretion**: 샘 자체 문제
- **Secondary hyposecretion**: tropic hormone 결함
- **Primary hypersecretion**: 샘 자체 과다분비
- **Secondary hypersecretion**: 외부 과도 자극

**CRH-ACTH-Cortisol 이상 감별**:
- CRH↑, ACTH↑, Cortisol↑ → **시상하부** 문제 (negative feedback 실패)
- CRH↓, ACTH↑, Cortisol↑ → **뇌하수체** 문제
- CRH↓, ACTH↓, Cortisol↑ → **부신** 문제

**Target cell responsiveness 조절**:
- Down regulation: 고농도 insulin에 target cell 둔감화
- Permissiveness(허용효과): TH에 의한 epinephrine receptor 발현 유도
- Synergism: FSH + testosterone → sperm 생산
- Antagonism: Progesterone이 estrogen receptor 발현 억제 → 자궁수축 방지 (임신 유지)

#### 8. 뇌하수체 생리

**뇌하수체 후엽 (Neurohypophysis)**:
- 시상하부의 신경조직 extension
- 호르몬을 **생산하지 않고 저장·분비만** 함 (★★★ 핵심)
- Paraventricular nucleus → **Oxytocin** (자궁수축, 모유생산)
- Supraoptic nucleus → **Vasopressin (ADH)** (수분 재흡수, 혈압 상승)

**Vasopressin 작용 경로**: 탈수 → 혈액 삼투압↑ → osmoreceptor 활성화 → 뇌하수체 후엽에서 ADH release → 신장 distal collecting tubule의 basolateral membrane receptor 결합 → cAMP↑ → aquaporin 발현↑ → 수분 재흡수↑ → 혈압↑

**Vasopressin 분비 조절**:
| 자극 | 억제 |
|---|---|
| 세포외액 삼투압↑ | 세포외액 삼투압↓ |
| 부피·압력 감소 | 부피 증가 |
| Angiotensin II | α-Adrenergic agonists |
| Pain, Stress | GABA |
| 온도 증가 | **Ethanol** |
| 뇌척수액 Na⁺ 증가 | **Cortisol**, Thyroid hormone |

**뇌하수체 전엽 (Adenohypophysis)**:
- 샘조직 구성, 시상하부와 **portal system**으로 연결 (혈관 통해 간접 조절)
- Portal system 의의: 소량의 시상하부 호르몬이 희석 없이 전엽에 집중적으로 전달됨
- **6가지 호르몬 생산**: TSH, ACTH, FSH, LH, GH(+IGF-1 간접작용), PRL

**시상하부 releasing/inhibiting hormones**: TRH, CRH, GHRH, GnRH, PRH, GHIH(somatostatin), PIH(dopamine)

**Hypothalamus-Pituitary-Adrenal Axis**: Stress → CRH↑ → ACTH↑ → Cortisol↑ → negative feedback (ACTH, CRH 억제)

**성장에 영향 주는 호르몬**: GH (주) + **Thyroid hormone + Insulin + Androgen + Estrogen**

**Melatonin (Pineal gland)**:
- 어두울 때만 분비 (Light-dark cycle 조절)
- 기능: 수면 유도, 생체주기 유지, 사춘기 억제, antioxidant, 면역력 향상
- Circadian rhythm (24시간 주기) 조절

## 2교시: 부신호르몬종류, 작용, 평가 (강양호 교수님)

> **⚠️ 주의**: 섹션 제목은 "부신호르몬종류, 작용, 평가"이나 실제 강의 내용은 **뇌하수체 전엽호르몬 작용·조절·평가 (3교시) + 뇌하수체 전엽 기능 항진 (4교시)**임. 두 교시 내용이 통합 제공됨.

---

### 핵심 개념

#### 1. 뇌하수체 전엽 6가지 호르몬 (절대 필수 암기)

| 호르몬 | 약자 | 기능 |
|---|---|---|
| **Prolactin** | PRL | 유즙분비 유지, reproductive function 감소 |
| **Growth hormone** | GH | 성장 촉진, 대사 조절 (간 → IGF-1) |
| **Adrenocorticotropic hormone** | ACTH | 부신피질 자극 → cortisol 분비 (stress 호르몬) |
| **Luteinizing hormone** | LH | 황체형성, 배란 |
| **Follicle-stimulating hormone** | FSH | 여포 발달, estrogen 분비 자극 |
| **Thyroid-stimulating hormone** | TSH | 갑상선 자극 → T3/T4 분비 |

#### 2. 시상하부-뇌하수체-표적기관 축 (5가지 축)

**Positive (자극) 축 4개**:
1. **CRH** → corticotroph → **ACTH** → 부신 → **cortisol**
2. **TRH** → thyrotroph → **TSH** → 갑상선 → **T3/T4**
3. **GnRH** → gonadotroph → **LH/FSH** → 성선 → **estradiol/testosterone**
4. **GHRH** → (somatostatin 억제) → somatotroph → **GH** → 간 → **IGF-I**

**Negative (억제) 축 1개 ★ 유일한 inhibitory axis**:
5. **Dopamine** → lactotroph **억제** → **prolactin↓**
   - 도파민 분비 문제 → prolactin 증가
   - 다른 4개 축과 완전히 다른 방향 (자극이 아닌 억제)

**추가 관계**:
- TRH는 TSH뿐 아니라 **PRL 분비도 촉진** → 갑상선기능저하증 시 TRH↑ → PRL↑
- SRIF(somatostatin): GH와 TSH 모두 억제
- 각 말초 호르몬 → 시상하부·뇌하수체에 **negative feedback**

**호르몬 주기**:
- Ultradian: 24시간보다 짧은 주기 (임상 의미 적음)
- **Circadian** (P): 24시간 주기 (스테로이드 호르몬, ACTH)
- Infracardian: 24시간보다 긴 주기 (월경주기 ~28일)

#### 3. Pituitary Mass Effect

**성장 방향별 영향**:
- **위 (suprasellar)**: optic chiasm 압박 → **시야장애** (가장 흔함)
- 측면 (lateral): 신경절 압박 → 신경 증상
- 아래: sphenoid sinus 침범 (드묾)

**구조별 임상 증상**:
| 손상 구조 | 임상 증상 |
|---|---|
| Pituitary | Hypogonadism, Hypothyroidism, Growth failure, Hypoadrenalism |
| **Optic chiasm** | **Bitemporal hemianopsia** (양측 측두 시야 소실) ★★★ |
| Hypothalamus | 식욕 이상, 온도조절 장애, 행동장애 |
| Cavernous sinus | 관련 신경 증상 |
| Brain | 두통 (가장 흔한 일반 증상) |

**치료**: Endonasal approach를 통한 **transsphenoidal resection** (코 통해 접근)
- 과거: 개두술 → 현재: sphenoidal sinus 통해 접근

#### 4. Pituitary Adenoma 종류와 빈도

| 세포 기원 | 질환 | 생산 호르몬 | 빈도 (%) |
|---|---|---|---|
| Somatotroph | Acromegaly, Gigantism | GH | 10-15 |
| **Lactotroph (prolactinoma)** | Hypogonadism, Galactorrhea | Prolactin | **25-40** (기능성 중 최고) |
| Corticotroph | Cushing's disease | ACTH | 10-15 |
| Gonadotroph | Mass effects, Hypopituitarism | FSH, LH | 15-20 |
| Thyrotroph | Hyperthyroidism | TSH | <3 |
| **Non-functioning/null cell** | Mass effects, Hypopituitarism | 없음 | **10-25** (실제 전체 최고 빈도) |

- Non-functioning: gonadotroph origin인 경우 많음. bitemporal hemianopsia, headache 유발 가능
- Mixed type: GH + prolactin 동시 증가 (acromegaly 진단 시 PRL도 확인 필수)

#### 5. Prolactin 및 Hyperprolactinemia

**정상 level**: 20 pg/mL 이하

**Hyperprolactinemia 원인 (5대 분류)**:

| 분류 | 세부 내용 |
|---|---|
| **Physiologic** | 임신 (GnRH/Gonadotropin 억제 → 재임신 방지), 수유, 흉벽 자극, 수면, 스트레스 |
| **Hypothalamic-pituitary stalk damage** | Craniopharyngioma★★★, Suprasellar pituitary mass, Meningioma, Trauma, Rathke cyst |
| **Pituitary hypersecretion** | Prolactinoma, Mixed GH+PRL adenoma (acromegaly) |
| **Systemic disorders** ★★★ | **Hypothyroidism** (TRH↑ → PRL 자극), CRF (renal clearance↓), Liver cirrhosis |
| **Drug-induced** | Dopamine antagonists, 항정신병약, H2 antagonists (cimetidine, ranitidine) — **임상에서 가장 흔함** |

**원인별 PRL 수치**:
- 약제: mild (<100)
- Hypothyroidism, CRF: moderate (<100)
- Pituitary adenoma: 높게 증가 (>200 가능)
- 임신: 매우 높게 증가

**Craniopharyngioma (구개인두종) 특징**:
- Benign suprasellar cystic mass
- Rathke's pouch 유래 → pituitary stalk 쪽 extending
- **Calcification 흔히 동반** → X-ray, CT에서 진단적 단서
- **Hypopituitarism 90%** 동반
- **Diabetes insipidus 10%** 동반
- 수술 후 평생 호르몬 replacement 필요 (부신피질호르몬, 갑상선 호르몬 필수)

**Hyperprolactinemia 증상**:
- 여성 3대 증상: **무월경 (amenorrhea) + 유즙분비증 (galactorrhea) + 불임 (infertility)**
- 남성: Libido 감소, infertility, visual loss (mass effect)
- 공통: 골감소증, 골다공증 (성선기능 저하 → 골밀도 감소)
- Idiopathic hyperprolactinemia: 약제·생리적·전신질환·MRI 모두 정상인데 PRL↑ → 특발성 (microadenoma 추정)

**치료**:
- 1차: **Dopamine agonist** (Bromocriptine, Cabergoline) → PRL 수치 감소
- 근본 치료: 원인 제거
  - 약제 원인: 중단 or dopamine agonist 병용
  - Hypothyroidism: 갑상선 호르몬 replacement → PRL 자연 감소
  - Mass: 수술 제거

#### 6. Prolactinoma (상세)

- 특징: **1cm 미만 microadenoma**, PRL **200 μg/L 이상** 증가
- **치료**:
  1. **Medical therapy (1st choice)**: Dopamine agonist (Bromocriptine, **Cabergoline**)
  2. Transsphenoidal resection
- **임신 고려 시**:
  - 임신 전 **Bromocriptine** 사용 → 임신 성공 후 **중단**
  - 임신 중 특별한 치료 불필요
  - ⚠️ **Cabergoline은 사용 금기** (teratogenic activity)

#### 7. Acromegaly (말단비대증)

- **원인**: GH 과다분비 (pituitary/extrapituitary) 또는 GHRH 과다분비
- **증상** (서서히 진행, ~10년):
  - 손·발 비대, 턱 돌출, 이마 돌출
  - 코골이, 수면 무호흡증
  - 목소리 굵어짐
  - 손에 땀
  - 내장 비대 (장기 비대)
- **진단**:
  1. **IGF-1 수치 확인** (선별)
  2. **Oral glucose tolerance test** (확진): 정상이면 GH 억제되어야 함 → 억제 안되면 acromegaly
- **치료**:
  1. Transsphenoidal resection
  2. Medical treatment: **Somatostatin analogues**

#### 8. Cushing's Syndrome / Disease

**Cushing's Syndrome**: 부신피질에서 Cortisol 과다 분비 (원인 무관)
- ACTH-dependent: ACTH 증가로 인한 cortisol 분비
- ACTH-independent: 부신 자체 문제

**Cushing's Disease**: 뇌하수체 ACTH 과다분비 (주로 corticotroph adenoma) → cortisol↑ (ACTH-dependent)

**증상**:
- 체중증가, **Moon face** (달모양 얼굴)
- 고혈압, 멍, 색소침착
- **자색선조 (purple striae)**
- 골다공증, 당뇨
- **Buffalo hump** (목 뒤 지방 축적)
- 가는 팔다리 (근육 위축)

**선별검사**:
1. **24시간 소변 유리 cortisol** (24-h urinary free cortisol)
2. **Overnight Dexamethasone 1mg suppression test**
3. ACTH Assay

**IPSS (Inferior Petrosal Sinus Sampling)**:
- ACTH-dependent 확인 후 pituitary vs ectopic ACTH 감별
- **Central 증가 시 → pituitary mass** (Cushing's disease)
- **Peripheral과 차이 없으면 → ectopic** (폐 종양 등)

**치료**:
1. Transsphenoidal resection (1st choice)
2. Medical adrenalectomy (약제로 부신 기능 억제 → cortisol 분비 차단)

**Nelson's Syndrome (부작용)**:
- Medical adrenalectomy 후 cortisol 감소 → negative feedback 소실
- ACTH 계속 과다분비 → **corticotroph mass 비대 + 피부 색소침착 (pigmentation)**
- 치료 어려움 ⚠️

**[2022] Q29. Prolactinoma에 대한 설명 중 옳은 것은?**

> ① 미세선종은 크기가 1cm 이상이다 ② Prolactin 수치가 200μg/L 이상 증가하는 경우는 드물다 ③ trans-sphenoidal approach 수술이 먼저 선택된다 ④ Bromocriptine으로 임신 시 계속 유지해야 한다 ⑤ 고프로락틴혈증이 있지만 다른 이유도 없고 MRI에서도 종양이 없는 경우를 특발성 고프로락틴혈증이라 한다

- **정답**: ⑤
- **해설**:
  - ① 미세선종(microadenoma) < 1cm (10mm 미만)
  - ② macroadenoma와 microadenoma 모두 200μg/L 이상 증가 가능
  - ③ Prolactinoma 1차 치료 = **dopamine agonist** (medical therapy). 수술(transsphenoidal)이 1차인 것은 말단비대증, Cushing's disease
  - ④ 임신 성공 후 bromocriptine 중단 (생리적으로 PRL이 올라가야 함)
  - ⑤ **옳은 설명** — idiopathic hyperprolactinemia 정의

**[2022] Q28. 호르몬 분비에 대한 설명 중 옳은 것은?**

> ① Dopamine은 prolactin 분비를 자극한다 ② Somatostatin은 GH 분비를 억제한다 ③ TRH는 prolactin 분비를 억제한다 ④ GnRH는 FSH 분비를 억제한다 ⑤ CRH는 ACTH 분비를 억제한다

- **정답**: ②
- **해설**:
  - ① Dopamine은 prolactin 분비를 **억제**
  - ② **옳음** — GHRH 분비 → somatostatin 억제 → GH 분비 증가 (somatostatin은 억제)
  - ③ TRH → TSH + **PRL 분비 증가** (자극)
  - ④ GnRH → LH + **FSH 분비 증가** (자극)
  - ⑤ CRH → **ACTH 분비 증가** (자극)

| Bitemporal hemianopsia | ★★★☆☆ 중간 | 주관식 출제 빈번 |
| Nonfunctioning adenoma = Gonadotrope | ★★☆☆☆ 중간 | 반복 출제 |
| Acromegaly 진단 (IGF-1, OGTT) | ★★☆☆☆ 중간 | 2020 출제 확인 |
| Cushing's disease 선별검사 | ★★☆☆☆ 중간 | 24h urine cortisol 2020 출제 확인 |

### 반복 출제 포인트

1. **뇌하수체 전엽 6대 호르몬** (PRL, GH, ACTH, LH, FSH, TSH): 무엇이 전엽, 무엇이 시상하부인지 구별 — 2012~2022 매년 출제
2. **Hyperprolactinemia 원인 패턴**: 항상 같은 원인 목록(임신·수유 / prolactinoma / hypothyroidism / CRF / 약제 / craniopharyngioma) vs 제외(Cushing, pheochromocytoma, 부신질환, hyperthyroidism) — 2011~2022 연속 출제
3. **Dopamine은 Prolactin을 억제** (자극이 아님): 시상하부-뇌하수체 연결에서 유일한 억제성 관계
4. **Prolactinoma 1차 치료 = Dopamine agonist** (Bromocriptine, Cabergoline), 수술이 아님; 말단비대증·Cushing's disease는 transsphenoidal resection이 1차
5. **임신 성공 후 Bromocriptine 중단**: 임신 중에는 PRL이 생리적으로 증가해야 하므로
6. **Bitemporal hemianopsia**: 뇌하수체 mass → optic chiasm 압박 (주관식 출제 2012·2013·2014)
7. **Nonfunctioning adenoma = Gonadotrope 연관**: 기능 검사 정상 + pituitary mass → gonadotrope

## (내분비학) 부신질환 - 강양호

> **주의**: 제공된 출족 섹션(3교시 부신질환)의 기출문제 내용이 2교시(부신호르몬종류, 작용, 평가) 섹션의 문제와 동일하게 구성되어 있습니다. 이는 강양호 교수님이 두 수업 모두 담당하시면서 출족이 합본 정리된 것으로 보입니다.

따라서 **문제 목록은 위 2교시 섹션과 동일**하며, 아래에는 부신질환 파트에서 별도로 강조된 내용(summary 기반)을 정리합니다.

### 부신질환 관련 핵심 정리 (summary 기반)

#### Cushing's Syndrome vs Cushing's Disease

| 구분 | Cushing's Syndrome | Cushing's Disease |
|------|-------------------|------------------|
| 정의 | 부신피질에서 Cortisol 과다 분비 | 뇌하수체에서 ACTH 증가 → 부신피질 Cortisol 증가 |
| 분류 | ACTH-dependent / ACTH-independent | ACTH-dependent |
| 증상 | 체중증가, moon face, 고혈압, 멍, 자색선조, osteoporosis, 당뇨, buffalo hump, 가는 팔다리 | 동일 |
| 선별검사 | — | ① **24h urinary free cortisol** (2020 출제) ② Overnight dexamethasone 1mg ③ ACTH assay |
| 치료 | — | ① Transsphenoidal resection (1st choice) ② Medical adrenalectomy |
| 합병증 | — | **Nelson's syndrome**: 부신절제 후 ACTH 계속 분비 → mass 커짐 + hyperpigmentation |

#### ACTH-dependent 시 감별: IPSS

- **Inferior Petrosal Sinus Sampling (IPSS)**: pituitary mass vs ectopic mass 감별
- Central(뇌하수체 정맥) : Peripheral 비율이 높으면 → pituitary mass

#### Acromegaly (말단비대증)

| 항목 | 내용 |
|------|------|
| 원인 | GH 과다분비 (pituitary/extrapituitary) 또는 GHRH 과다분비 |
| 증상 | 서서히 진행(10년), 손·발 커짐, 턱 나옴, 코골이, 수면무호흡, 장기비대 |
| 진단 | **IGF-1 수치 확인** (2020 출제) → oral glucose tolerance test로 확진 |
| 치료 | ① Transsphenoidal resection (1st choice) ② Somatostatin analogues |

### 출제 경향 분석

출족 내 기출문제가 2교시와 동일하므로, 부신질환 파트에서 독자적으로 자주 출제된 핵심 주제는 다음과 같습니다:

| 주제 | 특이사항 |
|------|----------|
| Cushing's syndrome 증상 | 다양한 증상 암기 필요 |
| 24h urinary free cortisol | 2020년 출제 확인 |
| IPSS (inferior petrosal sinus sampling) | ACTH-dependent 시 감별검사 |
| Nelson's syndrome | medical adrenalectomy 합병증 |
| Acromegaly 진단 (IGF-1 → OGTT) | 2020년 출제 확인 |

### 반복 출제 포인트

1. **Cushing's disease 선별검사 3종**: 24h urinary free cortisol / Overnight dexamethasone 1mg suppression test / ACTH assay
2. **ACTH 의존성 분류**: ACTH-dependent(뇌하수체/이소성) vs ACTH-independent(부신 종양)
3. **Nelson's syndrome**: 의약적 부신절제 후 ACTH 분비 지속 → 종양 성장 + 색소침착
4. **Acromegaly 진단 순서**: IGF-1 (선별) → OGTT (확진)
5. **치료 1st choice 비교**:
   - Prolactinoma → Dopamine agonist
   - Acromegaly → Transsphenoidal resection
   - Cushing's disease → Transsphenoidal resection

## 1. (내분비학) 부신호르몬 생리 — 권상모 교수님
**수업일:** 10.26(목) 1교시

---

### 📌 핵심 요약 (Summary)

| | 토리층 (zona glomerulosa) | 다발층 (zona fasciculata) | 그물층 (zona reticularis) | 속질 (medulla) |
|---|---|---|---|---|
| **호르몬** | Aldosterone | Cortisol | DHEA(S) | Epinephrine, Norepinephrine |
| **기능** | Na⁺/K⁺ 전해질 균형 | 대사, 스트레스, 항염증 | 2차 성징(여성) | Fight or flight |
| **조절** | Renin-Angiotensin | HPA axis (CRH→ACTH) | HPA axis (CRH→ACTH) | Preganglionic sympathetic fiber |

---

### 1. 부신의 구조

- 양쪽 콩팥 위에 위치. **부재 시 치명적** (갑상샘과 달리 생명 유지에 필수적)
- **겉질(cortex, 80%)** + **속질(medulla, 20%)** 으로 구성 — 발생학적 기원이 다름
- 겉질은 3층: 토리층 → 다발층 → 그물층
- 층마다 다른 효소가 존재 → 동일한 cholesterol 전구체로 서로 다른 호르몬 합성

---

### 2. 부신겉질 호르몬 합성 (★출제 빈출★)

- 세 가지 호르몬 모두 **콜레스테롤**에서 유래
- **21-hydroxylase (CYP21A2)** ⭐⭐: Aldosterone·Cortisol 합성에 필수. Mutation → 두 호르몬 결핍
  - DHEA 합성에는 관여하지 않음
- **Aromatase (방향화효소)** ⭐: Androgen → Estrogen 합성. 유방암 치료에서 **Aromatase inhibitor** 사용

---

### 3. Mineralocorticoids — Aldosterone

- **Action site:** 신장의 distal and collecting tubules
- 분비 증가 기전 2가지:
  1. **RAAS 활성화** (혈중 Na⁺ 감소 또는 혈압 하강 → renin 분비 → aldosterone 분비)
  2. 혈중 **K⁺ 증가** → adrenal cortex 직접 자극
- **ACTH와 무관**하게 독립적 조절 ⭐

---

### 4. Glucocorticoids — Cortisol ★★★ (매년 출제)

#### 4가지 주요 기능
1. **Metabolic effect** (가장 중요) ⭐⭐
   - 간에서 gluconeogenesis 촉진
   - 뇌 제외 조직의 glucose uptake 감소
   - protein degradation, lipolysis → glucose 공급
2. **Permissive actions** (허용효과)
   - Catecholamine이 혈관을 수축하려면, glucagon이 합성되려면 → cortisol 필요
3. **Stress response** (스트레스 호르몬)
   - **일주기성:** 오전 8시 peak → 저녁 nadir (멜라토닌과 반대)
4. **항염증·면역억제** 효과
   - 이식 거부반응 예방, 류마티스 관절염 초기 치료
   - 장기 사용 부작용: 감염 저항 저하, 위궤양, 고혈압, 생리불순, **HPA axis 위축 (atrophy)**⭐

#### HPA axis 위축 효과 ⭐⭐⭐
- 3주 이상 고용량 exogenous corticosteroid 투여 시
- Hypothalamus·Pituitary에 negative feedback → CRH·ACTH 분비 극단 억제
- 결과: Zona fasciculata 위축 → 영구 불능 가능
- **따라서 steroid 치료 중단 시 점진적으로 용량 감량 필요**

---

### 5. Sex Hormones (Adrenal Androgens)

- **DHEA**: 부신에서 가장 풍부한 성호르몬. 남성화·여성화 충분하진 않지만 생리적으로 중요
- 여성: pubic & axillary hair 성장, 사춘기 성적 발현, 생식기능 성숙·유지
- **ACTH에 의해 조절되지만, Androgen은 CRH·ACTH에 대한 negative feedback 불가** ⭐⭐
  - → 대신 **GnRH를 억제**

---

### 6. 부신겉질 기능 이상 (Disorders) ★ 매년 출제

| 질환 | 기전 | 주요 증상 |
|---|---|---|
| **Primary hyperaldosteronism (Conn's syndrome)** | 부신 종양 → aldosterone 과다 분비 | 고혈압, hypokalemia, Na⁺ retention |
| **Secondary hyperaldosteronism** | 신동맥 협착 → RAAS 과활성 | 고혈압 |
| **Cushing's syndrome** | ACTH 과다 / 부신 종양 → cortisol 과다 | Hyperglycemia, moon face, buffalo hump, 멍, 골다공증 |
| **Adrenogenital syndrome (부신생식기 증후군)** ⭐⭐⭐ | 21-hydroxylase deficiency → cortisol 부족 → ACTH↑ → androgen 과다 | 여성 남성화, 여성 가성반음양, 불임 |
| **Addison's disease** | 자가면역 → 부신피질 파괴 | 스트레스 반응 저하, 저혈당, 저혈압, hyperpigmentation |

#### Adrenogenital syndrome 기전 ⭐⭐⭐
```
21-hydroxylase 결핍
→ Cortisol 합성 불가
→ HPA axis negative feedback 안 됨
→ ACTH 급증
→ DHEA(Androgen) 과잉 생산
→ (Androgen은 ACTH를 억제 못하고) GnRH 억제
→ Gonadotropin 감소 → 불임
```
- 치료: Exogenous glucocorticoid replacement (ACTH 억제 → Androgen 과잉 분비 차단)

---

### 7. 부신속질 (Adrenal Medulla)

- 기원: Embryonic neural crest
- Modified postganglionic sympathetic cells (chromaffin cells)
- **Catecholamine** 분비: **Epinephrine : Norepinephrine = 3:1** (Epi이 major)
- 합성 경로: Tyrosine → DOPA → Dopamine → Norepinephrine → **Epinephrine** (순차적)
- Fight or flight response: HR·BP↑, 혈관수축, 기관지확장, 혈당·지방산 증가

---

### 8. Stress Response ★ (2022 출제)

스트레스 상황 시 시상하부의 통합 조절:
1. 교감신경 활성화 + **Epinephrine** 분비 (fight-or-flight)
2. **CRH→ACTH→Cortisol** axis 활성화 (가장 중요한 pathway) ⭐
3. 혈당·지방산 증가 (insulin 감소, glucagon 증가)
4. **RAAS 활성화** + Vasopressin 분비 → 혈압·혈량 유지

## 2. (내분비학) 부신호르몬 종류, 작용, 평가 — 강양호 교수님
**수업일:** 10.26(목) 2교시

---

### 📌 핵심 Summary — 검사 선택 원칙

```
호르몬 분비 부족 → 자극검사 (Stimulation test)
호르몬 분비 과다 → 억제검사 (Suppression test)
```

| 상황 | Glucocorticoid | Mineralocorticoid |
|---|---|---|
| **자극 (부족 시)** | Rapid ACTH stimulation test, Insulin-induced hypoglycemia test, Metyrapone test, CRH stimulation test | Volume depletion, Na restriction, Loop diuretic, Upright posture |
| **억제 (과다 시)** | Overnight / Low dose / High dose Dexamethasone suppression test | **Normal saline infusion (loading) test** |

---

### 1. 부신피질 3가지 스테로이드 (2022 출제)

| | Glucocorticoid | Mineralocorticoid | Adrenal Androgen |
|---|---|---|---|
| 호르몬 | Cortisol | Aldosterone | DHEA(S) |
| 분비층 | Zona fasciculata (다발층) | Zona glomerulosa (토리층) | Zona reticularis (그물층) |
| 조절 | HPA axis | RAA system | HPA axis |
| 기능 | 대사·면역·스트레스 | 혈압·전해질 | 2차 성징 |

> ⚠️ **주의:** 교수님 강의록에서 "토리층=glomerulosa=Aldosterone"이 맞음. 학습목표 순서와 일치

---

### 2. 11β-HSD ★★★ (2021·2022 출제)

- Cortisol 대사의 마지막 단계 관여하는 주요 효소
- **11β-HSD 1**: Cortisone(inactive) → **Cortisol(active)** ⭐
- **11β-HSD 2**: Cortisol(active) → **Cortisone(inactive)** ⭐

#### Mineralocorticoid receptor(MR) 교차 반응
- Cortisol도 MR에 거의 동일한 친화도로 결합 ⭐ (2021-1 출제)
- High dose glucocorticoid → mineralocorticoid-like effect → mineralocorticoid deficiency 커버 가능
- 반대로 Aldosterone은 glucocorticoid receptor에 결합 불가

---

### 3. HPA axis — Cortisol 분비 조절

- **Circadian rhythm**: 오전 분비 多, 저녁 분비 少
- Stress(신체적/심리적/생리적) → Cortisol 분비 급증
- Adrenal insufficiency 환자 + stress → 저혈압·쇼크·사망 위험

---

### 4. Glucocorticoids 대사 작용

- 인슐린 길항 → 혈당 증가 → 당뇨 유발 가능 ⭐
  - 인슐린 저항성 유발 질환: **Acromegaly, 쿠싱증후군, 갈색세포종** ⭐
- Protein catabolism → central obesity + peripheral atrophy (말초 가늘어짐)
- Anti-inflammatory: 류마티스 관절염, 이식 후 면역억제, Graves ophthalmopathy 초기

---

### 5. Mineralocorticoids — Renin-Angiotensin 생리

**RAAS 작용 순서:**
```
혈압 저하 / Na⁺ 감소
→ Kidney JG cell에서 Renin 분비
→ Angiotensinogen → Angiotensin I
→ ACE → Angiotensin II
→ Aldosterone 분비
→ Na⁺ retention, K⁺ excretion → 혈압·혈량 회복
```

#### Primary aldosteronism에서 핵심 ⭐⭐
- **Hypernatremia는 잘 안 생김**: natriuresis(Na⁺ 소변 배출)로 자정 작용 → escape phenomenon
- **Hypokalemia는 지속됨**: K⁺은 escape phenomenon 없음 ⭐⭐
- **Edema도 잘 안 생김**: Na⁺ natriuresis로 volume 크게 안 늘어남

---

### 6. Glucocorticoid 검사 ★★★

#### 선별검사 (Cushing syndrome)
| 검사 | 방법 | 특징 |
|---|---|---|
| **24hr urine free cortisol (UFC)** | 소변 24시간 수집 | 외래 가능. 가장 선호 ⭐ |
| **Overnight dexamethasone suppression test** | 자기 전 1mg dexamethasone → 아침 cortisol 측정 | 억제 안 되면 (>5μg/dL) 이상 |
| Midnight plasma cortisol | >130nmol/L | Circadian rhythm 소실 확인 |

#### 자극검사 (부신기능저하증)
| 검사 | 목적 |
|---|---|
| **Rapid ACTH stimulation test** ⭐⭐⭐ | 가장 기본 자극검사. HPA axis 확인. Iatrogenic cushing 진단에 유용 |
| **Insulin-induced hypoglycemia test** | 뇌하수체 기능저하증(Hypopituitarism) 진단. 심혈관·발작 질환 금기 |
| Metyrapone test | 11β-hydroxylase 억제 → cortisol 억제 → ACTH↑ 확인 (잘 안 함) |
| CRH stimulation test (IPSS) | Cushing에서 pituitary vs ectopic 감별 |

#### 확진검사 (Cushing syndrome)
| 검사 | 목적 |
|---|---|
| **Low dose dexamethasone suppression test** ⭐⭐ | Pseudo-Cushing 감별. 확진검사 |
| **High dose dexamethasone suppression test** ⭐⭐ | Cushing syndrome 원인 감별 (pituitary vs ectopic vs adrenal) |

---

### 7. Mineralocorticoid 검사

#### 선별검사 (고알도스테론혈증)
- **Aldosterone-Renin Ratio (ARR)** ⭐⭐: aldosterone↑, renin↓ → ARR 매우 상승 → 의심
- 검사 전 K⁺ 정상화 필요

#### 확진검사
- **Normal saline infusion (loading) test** ⭐⭐⭐ (이름에 suppression 없으나 억제검사)
  - 4시간 동안 2L normal saline IV → aldosterone이 5ng/dL 이하로 억제되어야 정상
  - 억제 안 되면 → primary aldosteronism 확진
  - 금기: 심부전, 심장 기능 저하. 시행 전 K⁺ 교정 필수

## 3. (내분비학) 부신 질환 — 강양호 교수님
**수업일:** 10.26(목) 3-4교시

---

### 📌 핵심 Summary

#### [쿠싱증후군 의심 소견]
1. **Fragility of skin**: easy bruising, broad(>1cm) **purplish striae** ⭐⭐ (0.4cm 이하 또는 백색이면 틀린 보기!)
2. **Signs of proximal myopathy**: 허벅지 근육 약화 (앉았다 일어나지 못함) ⭐
3. Gluconeogenesis·lipolysis·protein catabolism 증가
4. DVT, PE, 정신질환, 심혈관 질환 위험 증가 ⭐
5. 입술·구강 점막 색소침착 ⭐

---

### 1. Cushing Syndrome 병인 (★ 매년 출제)

```
내인성 ┬ ACTH-dependent (ACTH↑, Cortisol↑)
       │   ├ Cushing's DISEASE: 뇌하수체 corticotrope adenoma (가장 흔한 내인성)
       │   └ Ectopic ACTH: Bronchial carcinoma, Small-cell lung cancer,
       │                   Pancreatic carcinoid, Medullary thyroid Ca, Pheochromocytoma
       └ ACTH-independent (ACTH↓, Cortisol↑)
           ├ Adrenocortical adenoma (대부분)
           ├ Adrenocortical carcinoma ⭐
           └ Nodular adrenal hyperplasia

의인성 (Iatrogenic) - 임상적으로 가장 흔한 원인! ⭐⭐
       류마티스 관절염, 자가면역, 항염증 목적 exogenous glucocorticoid 복용
       → Rapid ACTH stimulation test로 확인
```

> **Cushing's disease** = Cushing syndrome 중 특히 pituitary corticotrope adenoma에 의한 것

---

### 2. 임상 양상

#### 비특이적 (Non-specific)
- 중심성 비만, 체중 증가, buffalo hump, 고혈당, 확장기 고혈압, 다모증, 우울증

#### 특이적 (Specific) ⭐ (2021-1 출제)
- **Skin fragility**: easy bruising, broad(>1cm) **purplish** striae
- **Buffalo hump**
- **Proximal myopathy**: 허벅지 무력 (앉았다 일어나지 못함)
- DVT·PE, 정신질환, 심혈관 질환 위험 증가
- 골다공증: steroid + 성선기능저하
- 입술·구강 점막 색소침착

#### 스테로이드 약제별 상대적 활성도 (2021 출제)
| 약제 | Glucocorticoid action | Mineralocorticoid action |
|---|---|---|
| Hydrocortisone (cortisol) | 1 | 1 |
| Prednisolone | ~4 | 약 |
| Methylprednisolone | ~5 | 미미 |
| Dexamethasone | 30-40 ⭐ | 0 |
| Fludrocortisone | 약 | 매우 강 ⭐ |
| Triamcinolone | ~5 | 0 |

### 3. 진단 Algorithm ★★★ (매년 출제)

```
① 임상적 의심 (증상 확인)
        ↓
② 선별검사 (2가지 이상 양성 시 확진 방향)
   - 24hr urine free cortisol ⭐ (외래)
   - Overnight dexamethasone suppression test (입원)
   - Midnight plasma cortisol (>130nmol/L)
        ↓
③ 확진검사
   - Low dose DEX suppression test
     - 억제 O → Pseudo-Cushing (음성, 쿠싱 아님)
     - 억제 X → Cushing 확진
        ↓
④ Plasma ACTH 측정 ★
   - ACTH >15pg/mL → ACTH-dependent
   - ACTH <5pg/mL  → ACTH-independent
        ↓
⑤ 감별진단
   ACTH-dependent → Pituitary MRI + High dose DEX test
     - High dose에서 억제 O (95%, microadenoma) → Cushing's disease
       치료: Trans-sphenoidal approach + tumorectomy
     - High dose에서 억제 X → Ectopic ACTH
       치료: Ectopic ACTH source 제거 (chest CT 먼저)
       (애매하면 IPSS 시행)
   
   ACTH-independent → Adrenal CT
     - Unilateral mass → Laparoscopic adrenalectomy
     - Bilateral mass → Bilateral adrenalectomy
```

---

### 4. 4가지 원인 감별표 ★★★ (매년 출제)

| | Pituitary macroadenoma | Pituitary microadenoma | Ectopic ACTH | Adrenal tumor |
|---|---|---|---|---|
| **Plasma ACTH** | ↑~↑↑ | Normal~↑ | ↑↑↑ | **★↓★** |
| **High dose DEX** | 억제 X (<10%) | **억제 O (95%)** ⭐⭐ | 억제 X (<10%) | 억제 X (<10%) |
| **CRH (IPSS)** | 반응 O (>90%) | 반응 O (>90%) | 반응 X (<10%) | 반응 X (<10%) |

> ⭐ **핵심 감별 포인트**: Adrenal tumor → ACTH가 낮음 (negative feedback으로 억제)

---

### 5. 치료

- **ACTH-independent**: 수술 (adrenal mass 제거) ⭐
- **Cushing's disease**: Trans-sphenoidal approach + selective removal ⭐ (2020 출제)
- **Ectopic ACTH**: Chest/Abdominal CT로 병소 찾아 제거
- **Medical adrenalectomy**: ketoconazole, metyrapone, mitotane
  - 부작용: **Nelson's syndrome** (cortisol 억제돼도 ACTH 계속 높음 → 색소침착, mass 커짐)
- **수술 후**: HPA axis 회복까지 1년(6~18개월) **hydrocortisone replacement** 필요 ⭐

---

### 6. 고알도스테론혈증 (Primary Aldosteronism)

#### 임상 양상 ⭐⭐ (2021 출제)
- **Potassium depletion, Sodium retention** ⭐ (가장 특징적)
  - Hypokalemia 지속 (escape 없음)
  - Hypernatremia는 잘 안 생김 (natriuresis로 자정)
- **Metabolic alkalosis** ⭐ (H⁺ 배출)
- **Hypokalemic hypertension** ⭐ (가장 특징적 양상)
- Edema 잘 안 생김

#### 진단 알고리즘
```
의심 소견: 약으로 안 되는 고혈압, hypokalemia, adrenal mass
        ↓
선별검사: ARR (aldosterone/renin ratio) ⭐⭐⭐
  ARR > 750pmol/L per ng/mL/hr + aldosterone 증가 → 확진검사
        ↓
확진검사: Saline infusion test ⭐⭐
  2L normal saline IV 4시간 → aldosterone >5ng/dL → Primary aldosteronism 확진
  (금기: 심부전. K⁺ 교정 후 시행!)
        ↓
감별진단: Adrenal CT → Unilateral vs Bilateral
  Unilateral: Laparoscopic adrenalectomy (수술 전 MR antagonist로 K⁺·혈압 교정!)
  Bilateral hyperplasia: Medical therapy (spironolactone, eplerenone) ⭐
  GRA: Dexamethasone 치료 ⭐ (2022 출제)
```

#### 원인
- **Primary aldosteronism (m/c)**: aldosterone-producing adrenal adenoma (Conn's syndrome)
- Bilateral adrenal hyperplasia
- **GRA (Glucocorticoid-remediable aldosteronism)**: ACTH에 의해 aldosterone 생성 → glucocorticoid로 치료, 가족력 확인, genetic testing ⭐

---

### 7. 갈색세포종 (Pheochromocytoma)

#### ⭐ PP 교수님이 기억해달라고 하신 핵심 7가지

1. **관련 germline mutation 유전자**: RET, VHL, NF1, SDH, **MEN2** (MEN1은 무관! ⭐)
2. **최고의 선별검사**: 24-hr urinary metanephrine ⭐⭐
3. CT/MRI로 안 보일 때: **MIBG scintigraphy** ⭐⭐⭐
4. **수술 전 혈압 조절**: 2주 이상 **α-adrenergic blockers 먼저!** (phenoxybenzamine, prazosin) → 그 후 필요 시 β-blocker ⭐⭐⭐
5. **수술 전 수액 공급**: Normal saline (수술 후 급격한 저혈압 방지)
6. **근본 치료**: 수술적 완전 절제
7. **우연종 발견 시 screening 순서**: 갈색세포종 → 쿠싱 → 고알도스테론혈증 → 암(4cm↑)

#### 임상 증상 ⭐
- **Classic Triad**: 심계항진(palpitation), 발한(sweating), 두통(headache)
- 고혈압 (지속적 or 발작적 episodic hypertension)
- 당뇨 유발 가능 (catecholamine → 인슐린 저항성) ⭐
  - 내분비 3대 혈당 상승 질환: **Acromegaly, Cushing's syndrome, Pheochromocytoma** ⭐

#### 진단
- **우선**: 생화학적 검사 (catecholamine·metanephrine 증가 확인)
  - **24-hr urinary metanephrine**: 가장 유용한 선별검사 ⭐⭐⭐ (plasma보다 더 안정적)
- **영상**: 복부 CT·MRI
  - Extra-adrenal 또는 paraganglioma 의심 시: MRI가 CT보다 유리
  - CT/MRI로 병소 확인 안 될 때: **MIBG scan** ⭐⭐⭐

#### 수술 전 처치 ⭐⭐⭐
1. **반드시 α-blocker 먼저** (2주 이상): phenoxybenzamine, prazosin, terazosin, doxazosin
   - 베타 먼저 쓰면 혈관 수축 악화! 절대 금지!
2. 이후 필요 시 β-blocker 추가
3. 충분한 수액 보충 (수술 후 저혈압 방지)

#### 유전 관련 질환
- **MEN2** (RET gene): 갈색세포종 + medullary thyroid carcinoma ⭐
- **MEN1**은 갈색세포종과 무관 ⭐ (2022 출제)
- VHL, NF1 → adrenal tumor 빈도 높음
- SDH 계열 → 두경부 paraganglioma 빈도 높음

#### 부신 우연종 (Incidentaloma) 발견 시 알고리즘 ⭐⭐⭐
```
CT/MRI에서 우연히 adrenal mass 발견
        ↓
Screening for hormone excess (기능성 여부 확인)
- Plasma metanephrine/24hr urine metanephrine → 갈색세포종
- 24hr UFC + Overnight dexamethasone test → 쿠싱
- Plasma ARR → 고알도스테론혈증
- (4cm↑) 17-hydroxyprogesterone, DHEAS → 암
        ↓
양성 → 각 호르몬에 대한 확진검사 → 수술
음성 → CT 소견 확인
  - size ≥4cm AND HU >20 → Adrenal cancer likely → 추가검사/수술
  - size <4cm AND HU ≤20 → Benign → Discharge (추적 불필요)
```

## 4. (내분비학) 부신 기능저하증 — 김상수 교수님
**수업일:** 10.26(목) 6교시

### 📌 교수님 마지막 강조 사항
- Primary vs Secondary 구분 (ACTH, 임상양상)
- 가장 흔한 원인은 **steroid 노출** (cushingoid features 동반 가능)
- Cortisol의 특성, 측정 시점, 약 투여 시점

---

### 1. Cortisol의 특성 — Circadian Rhythm ⭐⭐⭐

| 시간 | 수치 |
|---|---|
| 자정 | 최저 (nadir) |
| 오전 8시 | **Peak** (10~20μg/dL) ⭐ |
| 오후 | 점차 감소 |

- 측정은 **이른 아침 (6~8시)**에! (오후 측정 시 위양성 가능)
- Morning cortisol **< 3μg/dL** → adrenal insufficiency 강력 시사 ⭐
- Morning cortisol **3~15μg/dL** → Rapid ACTH stimulation test로 확인
- Morning cortisol **> 15μg/dL** → 정상 가능성 높음
- Morning cortisol **> 18μg/dL** → 확실한 정상
- **밤에 복용하면 circadian rhythm 깨짐 → 아침 7시에 약 복용!** ⭐

### 2. Adrenal Insufficiency의 분류

| | Primary AI (Addison's disease) | Secondary AI | Tertiary AI |
|---|---|---|---|
| **병변** | 부신 자체 | 뇌하수체 | 시상하부 |
| **ACTH** | ↑↑ (↑) | ↓ 또는 정상 | ↓ 또는 정상 |
| **Cortisol** | ↓ | ↓ | ↓ |

| **흔한 원인** | Autoimmune, TB, Drug | **Chronic exogenous glucocorticoid (m/c)** ⭐⭐ | |

### 3. Primary AI 원인

1. **Autoimmune adrenalitis** (m/c)
   - Isolated (30~40%) / APS (60~70%)
   - APS2: thyroid autoimmune + vitiligo + type1 DM 등 동반
2. **결핵 (TB)** — 우리나라에서 흔함, 양쪽 침범
3. Adrenal infiltration: 전이, 림프종
4. Adrenal hemorrhage: 수막구균 패혈증
5. **Drug-induced**: mitotane, ketoconazole (steroidogenesis 방해)

---

### 4. Secondary AI 원인

- **m/c: Chronic exogenous glucocorticoid** ⭐⭐⭐ (2020·2021-2 출제)
  - HPA axis 억제 → endogenous cortisol 분비 저하
  - Reversible하지만 오래 걸림
- Pituitary disease (종양, hemorrhage)
- **Ipilimumab (anti-CTLA antibody)**: 면역관문억제제 항암제 → hypophysitis → secondary AI ⭐ (요즘 많음)

#### ⭐ Iatrogenic AI 관련 요인 (시험 출제 쉬운 내용)

| 요인 | 내용 |
|---|---|
| **용량** | Physiological replacement dosage(hydrocortisone 20mg/일 이하) 초과 시 위험 |
| **약제 반감기** | Long-acting(dexamethasone)일수록 위험 ↑ |
| **투여 시간** | 밤에 투여 시 circadian rhythm 깨짐 (아침에 복용해야!) |
| **투여 빈도** | 하루 여러 번 > 하루 1번 > 격일 |
| **투여 기간** | **3주 이내**가 좋음 (2020·2021-2·2022 출제) ⭐ |

### 5. 임상 양상 ⭐ (2020·2021-2 출제)

#### Primary AI
- Glucocorticoid + mineralocorticoid + androgen 모두 감소
- **Hyponatremia**: mineralocorticoid 부족
- **Hyperpigmentation** ⭐⭐⭐: ACTH↑ → POMC → MSH 증가 → 멜라노사이트 자극
  - 손금, 발등, 유두 주위, 겨드랑이, 구강 점막
- Hypokalemia, 저혈압

#### Secondary AI
- Glucocorticoid + androgen 감소 / **Mineralocorticoid는 정상** ⭐
- **Hyponatremia**: cortisol의 ADH 억제 작용 소실 → mild SIADH
- **Alabaster-like paleness** (창백, 푸석푸석)

#### H-P disease (Secondary AI)
- 다른 내분비축 이상 동반: 성욕 저하, 무월경 등
- Suprasellar mass → optic chiasm 압박 → **bitemporal hemianopia** ⭐

#### Iatrogenic AI
- **Cushingoid features** (외부 스테로이드 과다)
- 갑자기 중단 시 → adrenal insufficiency ⭐⭐

### 6. 진단

#### Serum cortisol 기준 ⭐⭐⭐

| Morning cortisol | 해석 |
|---|---|
| < 3μg/dL | AI 강력 시사 → ACTH stimulation test 시행 근거 |
| 3~15μg/dL | ACTH 자극검사로 확인 |
| > 15μg/dL | 대부분 정상 |
| > 18μg/dL | 확실한 정상 |

#### Rapid ACTH stimulation test (확진검사) ⭐⭐
- Cosyntropin 투여 → 30~60분 후 cortisol level 측정
- **Cut-off**: cortisol < **18μg/dL** → Adrenal insufficiency 진단
- Primary AI: high sensitivity / Secondary AI: 감별 다소 어려울 수 있음

#### 감별 지표
- **ACTH**: Primary↑ / Secondary 정상 or ↓
- **Plasma renin**: Primary↑ (mineralocorticoid 부족 → RAAS 활성화)
- **Aldosterone**: Primary↓ / Secondary 정상

---

### 7. 치료

#### Glucocorticoid replacement ⭐ (2020 출제)
- **Hydrocortisone 15~25mg/일**, 2~3회 분복 (short-acting이 가장 생리적)
- **절반 이상 아침에** 투여 (circadian rhythm 반영)
- Monitoring: **증상·징후**가 가장 중요. Plasma ACTH·24hr UFC는 큰 의미 없음 ⭐ (2021-2·2022 출제)
- **Stress 상황 시 (fever, 수술, 외상)**: 용량 2~3배 증량 교육 필수

#### Mineralocorticoid replacement (Primary AI에서만)
- **Fludrocortisone** 100~150μg/일
- 효과 판정: 기립 시 혈압 변화, 혈청 Na·K, plasma renin

#### Glucocorticoid 사용 전 체크리스트 (2021-2 출제)
- 결핵·만성 감염, 당뇨 위험인자, 골다공증, 소화성 궤양, 고혈압, 정신장애 여부 확인

#### Systemic Glucocorticoid 종류
| 종류 | 지속시간 | 효력 (hydrocortisone 대비) |
|---|---|---|
| Hydrocortisone | Short (<12hr) | 1 (가장 physiologic) |
| Prednisone | Intermediate (12~36hr) | 4배 |
| Methylprednisolone | Intermediate | 5배 |
| Dexamethasone | Long (>48hr) | 30~40배 ⭐ |

### 8. Adrenal Crisis (급성 부신기능저하증)

#### 유발 요인
- 만성 AI + 감염/수술/스트레스
- Glucocorticoid 갑자기 중단 ⭐
- GI 문제 (구토/설사) → 약물 흡수 불가

#### 증상
- Nausea, vomiting, abdominal pain (acute abdomen처럼 보임) ⭐
- Fever, confusion, coma
- **Hypovolemic shock** ⭐

#### 치료 원칙 (2021-1 출제)
1. **즉시 steroid replacement** — 진단 기다리지 말 것 ⭐⭐
   - Baseline cortisol만 채혈해두고 바로 투여
   - **Hydrocortisone 100mg bolus IV** → 이후 24시간 200mg
2. **Rehydration** (hypovolemic shock 치료)
3. Mineralocorticoid: 일일 hydrocortisone 50mg 미만이 되면 추가

## 5. (내분비학) 부신 증례 — 김상수 교수님

### Case 1. 쿠싱증후군 — 좌측 부신 선종 (2020·2021-2·2022 출제)

**환자:** 38세 여자 / 수년간 체중 증가, 멍 잘 듦

**이학적 소견:**
- 중심형 비만, 고혈압 (160/100)
- 팔·다리에 멍, 복부 굵은 striae

| 검사 | 결과 |
|---|---|
| Basal ACTH | ↓ (억제됨) |
| Cortisol | ↑ |
| 24hr UFC | 매우 ↑ |
| Low dose DEX | 억제 X (cortisol >1.8 μg/dL) → Cushing 확진 |
| High dose DEX | 억제 X |

**→ ACTH < 5pg/mL**: ACTH-independent Cushing's → **Adrenal CT** → 좌측 adrenal mass

#### Adrenal CT 해석 (Adenoma vs carcinoma/pheo 감별)
```
AEW (Absolute Enhancement Washout) = (EAV - DAV) / (EAV - UAV)
  > 60% → Adenoma

REW (Relative Enhancement Washout) = (EAV - DAV) / EAV
  > 40% → Adenoma
```

**진단:** Cushing syndrome due to Lt. adrenal adenoma  
**치료:** Laparoscopic adrenalectomy ⭐⭐ → **수술 후 반드시 steroid 보충** (일시적 adrenal insufficiency 발생)

### Case 2. 쿠싱증후군 — 뇌하수체 선종 (Cushing's disease)

**환자:** 40세 여자 / 1년간 체중 증가

**이학적 소견:** 고혈압, 복부 자색 선조, 중심성 비만

| 검사 | 결과 |
|---|---|
| Basal ACTH | 정상 (억제 X) |
| 24hr UFC | ↑ |
| Low dose DEX | 억제 X → Cushing 확진 |
| High dose DEX | **억제 O** → Pituitary-adrenal axis 살아있음 |
| Pituitary MRI | Hypodense mass 발견 |

**→ ACTH-dependent + high dose DEX 억제 O** → **Pituitary Cushing's disease**

**진단:** Cushing syndrome due to pituitary adenoma  
**치료:** **TSA (Trans-sphenoidal approach) + tumorectomy** ⭐⭐

### Case 3. Ectopic ACTH Syndrome — Carcinoid Tumor (★ 매년 출제 ★)

**환자:** 68세 여자 / 전신 쇄약, moon face

> ⭐ **반드시 medication(스테로이드 복용력) 먼저 물어볼 것!**  
> → 있으면: Iatrogenic → Rapid ACTH stimulation test  
> → 없으면: 쿠싱 진단 알고리즘 진행

| 검사 | 결과 |
|---|---|
| Basal ACTH, Cortisol, 24hr UFC | 모두 매우 ↑ |
| Low dose DEX | 억제 X |
| High dose DEX | **억제 X** → Ectopic 가능성 ↑ |
| Pituitary MRI | Microadenoma 의심 (애매) |

**→ 병변 위치 확인 위해:**
- **IPSS** 시행: Petrosal-to-Peripheral ACTH ratio < 3 → pituitary 아님
- **Chest CT**: Lung에 mass 발견
- **Biopsy**: Carcinoid tumor

**진단:** Lung carcinoid tumor에 의한 ectopic ACTH syndrome  
**치료:** Lung carcinoid tumor 제거

> **Ectopic ACTH producing tumor의 m/c**: Lung/mediastinal carcinoid, SCLC

### Case 4. 고알도스테론혈증 — 우측 부신 종양 (2020·2021-2·2022 출제)

**환자:** 47세 남자 / 조절 안 되는 고혈압, 무기력

| 검사 | 결과 | 정상 |
|---|---|---|
| K⁺ | **2.9 mEq/L** ⭐ | 3.5~5.0 |
| Plasma renin | 0.03 ng/mL/hr | **억제됨** |
| Aldosterone | 32 ng/dL | ↑ |
| **ARR** | **1066** | >30 → 의심 |

**진행:**
- ARR 매우 상승 → **Saline loading test** (확진)
  - 2L NS 4시간 → aldosterone 26.6 ng/dL (억제 안 됨, 정상 <5ng/dL)
  - → **Primary aldosteronism 확진**
- Adrenal CT → 우측 adrenal mass

**진단:** Primary aldosteronism due to right adrenal tumor  
**치료:** Laparoscopic right adrenalectomy ⭐⭐
> 수술 전 반드시 **MR antagonist (spironolactone 등)로 K⁺·혈압 정상화** ⭐⭐⭐

### Case 5. 갈색세포종 (2018·2019 출제)

**환자:** 50세 여자 / 수년간 발한·두통·심계항진, 최근 악화, 혈압 210/110

> ⭐ **Classic Triad (발한·두통·심계항진)** = 갈색세포종 반드시 의심!

| 검사 | 결과 | 정상 |
|---|---|---|
| 24hr urine catecholamine (NE) | 310.7μg | 0-80 |
| 24hr urine catecholamine (Epi) | 100.4μg | 0-40 |
| 24hr urine VMA | 12.5mg | 1.5-7.5 |
| **24hr urine metanephrine** | **3mg** | <1.2 |

#### Catecholamine 대사 경로
```
Tyrosine → DOPA/Dopamine → Epinephrine/Norepinephrine
→ Metanephrine/Normetanephrine → VMA → 소변 배출
```

**영상:**
- Adrenal CT: 좌측 heterogeneous mass → pheo 의심
- **131I-MIBG scan** ⭐⭐: 동일 부위에 iodine uptake → Functioning pheo 확진

**진단:** Pheochromocytoma (left)

**치료 ★★★ (출제 필수)**
- 수술 전 최소 **10~14일간 α-blocker 투여** (phenoxybenzamine, terazosin, doxazosin)
- 알파 먼저, 이후 stable해지면 beta-blocker 추가
- 충분한 수액 보충 후 수술

### Case 6. 부신 우연종 (Incidentaloma)

**환자:** 42세 남자 / 건강검진 중 좌측 신장 부위 종괴 우연 발견

**처치:**
1. **Functioning test** 시행: metanephrine, overnight DEX test, ARR, UFC
2. 호르몬 excess 없음 → CT 소견 중심
3. 경과 관찰 중 크기 증가 + hormonal hypersecretion → **수술 시행**

#### 부신 우연종 수술 적응증
- Functional adrenal tumor (cushing·aldosteronism·pheo) → 수술
- **Nonfunctional이라도 size ≥6cm** (또는 4cm 주장도 있음)
- 1년에 1cm 이상 크기 증가 or 호르몬 hypersecretion 발생

### Case 7. 결핵에 의한 Primary Adrenocortical Insufficiency

**환자:** 47세 여자 / 10개월간 전신 hyperpigmented macule

**증상:**
- **전신 hyperpigmentation** (혀·입술·얼굴 등) ⭐⭐ → **반드시 Primary AI 의심!**
- 7kg 체중 감소, 피로, Hyponatremia (Na 124 mEq/L)
- 양측 adrenal gland 이상 (CT)

**검사:**
- **Rapid ACTH stimulation test**: Cortisol 전혀 증가 안 됨 + ACTH 매우 높음 → Primary AI 확진
- Aldosterone도 상승 안 됨

**조직검사:**
- Granulomatous inflammation with caseous necrosis → **결핵 의심**
- PCR(+), TB IFN-γ(+) → **결핵 확진**

**치료:** Anti-TB medication (HERZ) + Glucocorticoid/Mineralocorticoid replacement
