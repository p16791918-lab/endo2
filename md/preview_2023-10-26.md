## 1교시 부신호르몬 생리 (권상모)

- **핵심 키워드**: Peptide/Amine/Steroid 호르몬, Hydrophilic vs Lipophilic, HPA axis, Negative feedback
- **핵심 개념 요약**:
  - 호르몬 종류 4가지: Peptide(가장 많음), Amine(tyrosine 유도체), Steroid(cholesterol 유도체), Fatty acid(eicosanoids)
  - **Hydrophilic**(Peptide, Catecholamine): 세포막 통과 불가 → membrane receptor → second messenger
  - **Lipophilic**(Thyroid, Steroid): 세포막 통과 → 세포 내 receptor → 직접 gene expression 조절
  - Peptide 호르몬: ER 합성 → Golgi packaging → secretory granule → exocytosis
  - Steroid 호르몬: cholesterol 전구체, lipid soluble → 저장 불가, simple diffusion으로 분비
- **교수 강조 포인트**:
  - 호르몬 receptor 위치: Thyroid/Steroid는 **세포 내부** [20出]
  - Amine 전구체: Tyrosine → dopamine/epi/norepi/thyroid H., Tryptophan → serotonin/melatonin
  - Hydrophilic/Lipophilic에 따라 저장·운반·수용체 위치·작용 기전 전부 달라짐 (PPP)

## 2교시 부신호르몬종류, 작용, 평가 (강양호)

- **핵심 키워드**: HPA/HPT/HPG axis, Dopamine-Prolactin axis, Hyperprolactinemia, Pituitary adenoma, Bitemporal hemianopsia
- **핵심 개념 요약**:
  - 시상하부-뇌하수체-말초기관 negative feedback이 내분비학 핵심
  - **예외**: Prolactin은 시상하부 dopamine에 의해 **억제** (다른 호르몬들은 자극) [15,11出]
  - Pituitary adenoma 빈도: lactotroph(25-40%) > nonfunctioning(10-25%) > somatotroph·corticotroph·gonadotroph(각 10-15%)
  - Pituitary mass → 위로 성장 → optic chiasm 압박 → **Bitemporal hemianopsia** [PPP, 14,13,12出]
  - 치료: 과거 개두술 → 현재 **transsphenoidal resection** (endonasal approach) [16出]
- **교수 강조 포인트**:
  - Dopamine 감소 → Prolactin 증가 메커니즘 필수 암기
  - Nonfunctioning/null cell이 **실제 임상에서 가장 빈도 높음**
  - TRH는 TSH뿐 아니라 PRL도 자극 → 갑상선기능저하 시 PRL도 상승 가능

## 3교시 부신질환 (강양호)

- **핵심 키워드**: Hyperprolactinemia 원인, Prolactin level, Craniopharyngioma, Dopamine agonist
- **핵심 개념 요약**:
  - Hyperprolactinemia 원인 4가지: ①Physiologic(임신·수유) ②Stalk damage ③Pituitary hypersecretion ④Systemic disorders ⑤Drug-induced [PPPP, 매년 出]
  - **Craniopharyngioma**: benign cystic mass, Rathke's pouch 유래, calcification 동반(진단적 clue), 90% hypopituitarism [PPPP出]
  - Prolactin level: 약제(20-70) < Hypothyroidism/CRF(<100) < Microadenoma(20-250) < Macroadenoma(200~10,000)
  - 여성 3대 증상: amenorrhea, galactorrhea, infertility
  - 치료: Dopamine agonist(Bromocriptine) + 기저 원인 치료
- **교수 강조 포인트**:
  - Drug-induced: dopamine receptor blocker, H2 antagonist(cimetidine) 장기복용
  - Systemic: chronic renal failure(clearance↓), hypothyroidism(TRH↑) 감별 필수
  - 수치 높을수록 adenoma 가능성, MRI 고려

## 6교시 부신 기능저하증 (김상수/강아름)

- **핵심 키워드**: HPA axis, Primary vs Secondary AI, Rapid ACTH stimulation test, Cortisol circadian rhythm, Adrenal crisis
- **핵심 개념 요약**:
  - 부신피질 3층: zona glomerulosa(aldosterone) / fasciculata(cortisol) / reticularis(androgen) [2020,2021-2出]
  - **Primary AI(Addison's)**: ACTH↑, cortisol↓, aldosterone↓ → hyperpigmentation(MSH), hyponatremia
  - **Secondary AI**: 원인 m/c = **만성 exogenous glucocorticoid 투여** [PPP] → ACTH↓, cortisol↓, aldosterone 정상
  - Cortisol 분비: 오전 8시 peak, 밤 nadir (circadian rhythm) [2021-2出]
  - 확진검사: **Rapid ACTH stimulation test** → 30-60분 후 cortisol <18μg/dL = AI [PPPPP]
- **교수 강조 포인트**:
  - morning serum cortisol: <3 → AI 강력 시사 / >18 → 정상
  - Hyperpigmentation은 **Primary AI에서만** (ACTH↑ → MSH↑)
  - Adrenal crisis 치료: **rehydration 1L/hr** + 100mg hydrocortisone bolus
  - Glucocorticoid 교체: Short-acting hydrocortisone이 가장 physiologic

## 7교시 부신 증례 (김상수/강아름)

- **핵심 키워드**: Cushing syndrome algorithm, ACTH level 감별, Primary aldosteronism ARR, Pheochromocytoma triad, Adrenal incidentaloma
- **핵심 개념 요약**:

| 질환 | 특징적 소견 | 확진/감별 검사 | 치료 |
|------|------------|------------|------|
| Cushing | central obesity, purple striae, buffalo hump | Low-dose DEX suppression test → ACTH 측정 | ACTH 억제→adrenal CT; ACTH 정상/높음→high-dose DEX/뇌하수체 MRI |
| Cushing(pituitary) | ACTH-dependent, high-dose DEX (+) | TSA tumorectomy |
| Cushing(ectopic) | ACTH-dependent, high-dose DEX (-) | IPSS (central:peripheral ratio ≥3) → Chest CT | ectopic tumor 제거 |
| Primary Aldosteronism | hypokalemia + HTN, ARR >20 | Saline loading test(aldosterone 억제 안 됨) | adrenalectomy or spironolactone |
| Pheochromocytoma | **두통·발한·심계항진 triad** + HTN | 24h urine catecholamine/VMA/metanephrine, MIBG scan | **수술 전 최소 10-14일 alpha blocker** 필수 [PPP,2018,2019出] |
| Adrenal Incidentaloma | 우연 발견 | Hormone screening → CT (size, HU) | >4cm 또는 >20HU → 수술 고려 |

- **교수 강조 포인트**:
  - Cushing 감별 핵심: **plasma ACTH 측정** 먼저 [PPP, 2018,2019出]
  - Primary aldosteronism: **ARR >20** 의심, saline loading으로 확진 [PPP]
  - Pheochromocytoma 수술 전 **alpha blocker 선투여 필수** (catastrophic hypotension 방지)
  - Adrenal TB: 양측 부신 침범 + hyperpigmentation → Primary AI 의심
