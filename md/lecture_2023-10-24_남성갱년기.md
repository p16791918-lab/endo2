## 강의 파일 핵심 내용

### 1. 정의 및 명칭
- **남성갱년기증후군 = TDS (Testosterone Deficiency Syndrome) = LOH (Late-Onset Hypogonadism)**
- 노화와 관련된 테스토스테론 저하 + 관련 증상이 존재하는 임상·생화학적 증후군

### 2. 테스토스테론 혈중 농도와 성기능 (ng/ml 단위)
| 수치 | 의미 |
|---|---|
| **1.4 ng/ml** | 야간 발기 및 심인성 발기 감소 (Carani 1996) |
| **2 ng/ml** | 성행위 가능 하한 (Salminies 1982) |
| **2~4 ng/ml** | 개인별 편차 구간 |
| **4 ng/ml** | 성기능 항상 유지 |

### 3. 나이에 따른 테스토스테론 감소 원인 (4가지)
① Leydig cell 기능 저하  
② LH로부터의 자극 감소  
③ Testosterone receptor 기능 저하  
④ SHBG 증가 → Bioavailable testosterone 감소

### 4. 동반 질환
- Obesity, Type 2 DM, MetS, Hypertension
- Work stress/anxiety/depression, Reduced muscle strength, Fracture risk

### 5. 자가 설문지
- **ADAM** (Morley 2000) — 선별 설문
- **AMS** (Heinemann 1999) — 증상 척도

### 6. 진단 기준
- 증상 확인 + 혈중 테스토스테론치 측정 (동시에)
- 혈액 채취: **가급적 오전**
- **≥300 ng/dl**: 정상 (치료 보류)
- **300 ng/dl(또는 350 미만)**: 치료 가능
- **<230 ng/dl**: 치료 적극 고려
- Free T / Bioavailable T / Salivary T → **초기 진단 시 권장하지 않음**
- *(ACP 기준, 2020: TT < 300 ng/ml)*

### 7. 유병율
- 전 세계 범위: **2.1~38.7%**
- 한국(부산, 2013, Total T ≤350 + ADAM 양성): **25.6%**

### 8. TRT 유익한 효과
Sexual Function · Bone mineral density · Cognitive function · Depression · Diabetes · MetS · Lipidemia · BMI

### 9. 치료 금기 및 주의점
| 구분 | 내용 |
|---|---|
| **절대 금기** | 전립선암, 남성유방암 |
| **상대적 금기** | 전립선 비대 (severe LUTS, IPSS>21), untreated sleep apnea, untreated severe CHF, Hct >52% |
| **일시적 보류** | CV event 후 **3~6개월** |

### 10. 남성호르몬 치료와 전립선
- 전립선암 위험 증가: **No conclusive evidence** (확실하지 않음)
- 하지만 전립선암 환자에서는 **금기** (정설 — locally advanced/metastatic PCa에서 증상 악화)
- BPH: 치료 시도 가능하지만 LUTS 심한 경우(IPSS>21) 상대적 금기

### 11. 전립선 모니터링 스케줄
- 직장수지검사(DRE) + PSA: **시작 전 / 3~6개월 후 / 12개월 후**
- **전립선암 징후 4가지**
  - DRE: 결절 촉지
  - **PSAV ≥ 0.75 ng/ml/year**
  - PSA 밀도 (PSA/전립선 volume): **≥ 0.15**
  - %free PSA (free/total PSA): **< 0.15**

### 12. CV Risk (AUA grading)
- TRT → CV risk 증가시키지 않는 것으로 보임 **(Grade B)**
- VTE 관련 확실한 근거 없음 **(Grade C)**
- CV event 후 3~6개월은 시작 금지 *(Expert Opinion)*

### 13. 치료제 종류 및 특성
| 제제 | 작용 시간 | 특이사항 |
|---|---|---|
| T. enanthate 근주 (4주, 250mg) | Short-acting | Roller-coaster 효과, 경제적, 병원 방문 필요 |
| T. undecanoate 근주 (12주, 1000mg) | Long-acting | 반감기 34일, 최고농도 11.4일 후, supraphysiologic peak 없음 |
| 경피용 Gel (Tostrex 2%) | Short-acting | 피부부작용 가능, 고령층 적합 (일일 도포 → 즉시 중단 가능) |
| Nasal Gel (NATESTO) | Short-acting | 비강내 도포, 이차 노출 없음 |
| 피하삽입제 (Pellet) | Long-acting | 자가 투여 불가, 국내 미사용 |

> **초기 치료 원칙: Short-acting 먼저** → 부작용 발생 시 빠른 중단 가능

### 14. 치료 목표 혈중 테스토스테론
- **젊은 남성 정상 범위의 Middle tertile (450~600 ng/dL)** (AUA Grade C)

### 15. 치료 평가 스케줄
| 평가 목적 | 시점 | 항목 |
|---|---|---|
| Outcome | 3~6개월 | Libido, sexual function, muscle function, body fat |
| Outcome | 2년 | Bone density |
| Safety | 3~6개월 | Signs/symptoms, weight, TT, Hct, PSA |
| Safety | 치료 전/3~6개월/12개월 | DRE + PSA |
| Follow-up | 6개월 미호전 시 | 치료 중단 고려, 다른 원인 탐색 |

## 정리족과의 비교

### ✅ 정리족과 일치하는 내용
- 정의 (노화 + 테스토스테론 저하 + 증상)
- 진단 기준: 증상 + 혈중 T 감소 (오전 채혈, 300/350 ng/dl 기준, 230 적극 고려)
- Free T / Bioavailable T / Salivary T 초기 권장 안 됨
- TRT 금기: 전립선암, 남성유방암; CV event 3~6개월 내 치료 보류
- 치료 전 DRE + PSA 검사 스케줄
- 전립선암 징후 4가지 (DRE 결절, PSAV, PSA 밀도, %free PSA)
- 치료제 종류: 4주 근주(short), 12주 근주(long), Gel(short)
- 치료 목표: 450~600 ng/dL
- 단기지속형 먼저 → 장기지속형 전환 원칙
- Outcome(3~6개월/2년) + Safety(3~6개월, DRE+PSA) 평가

### 🆕 강의에만 있는 새 내용 (중요!)

> 김현우 교수님이 이번 연도부터 새로 담당, **별표(\*) 표시 내용이 출제 포인트**

1. **테스토스테론 수치별 성기능 cutoff**: 1.4 / 2 / 4 ng/ml (각각 참고 문헌 포함)
2. **테스토스테론 감소 4가지 원인**: Leydig cell↓, LH 자극↓, T receptor↓, SHBG↑
3. **자가 설문지 ADAM, AMS** (이름 + 발표 연도)
4. **유병율 수치**: 2.1~38.7% (전 세계), 25.6% (한국)
5. **TRT 유익 효과 목록** (BMD, cognitive function, depression, DM, MetS, Lipidemia, BMI 포함)
6. **CV risk AUA Grade 분류** (B/C 등급 구체적 명시)
7. **T. undecanoate 약동학**: 반감기 34일, 최고 농도 11.4일 후, supraphysiologic peak 없음
8. **Tostrex 2% Gel 혈중 농도별 용량 조절표** (<300→4g, 300~450→3g, >450→2g)
9. **Nasal Gel (NATESTO)** 존재 및 장점
10. **ACP 기준** TT < 300 ng/ml (2020) 명시
11. **6개월 미호전 시 치료 중단 + 다른 원인 탐색** 알고리즘
12. **전립선 비대증 상세 기준**: IPSS >21 상대적 금기, 폐쇄 성공 치료 후 금기 아님
13. **제제 비교표** (6종 장단점 — 효능/생리적 농도/작용 시간/자가투여/경제성/부작용/통증)

### ⚠️ 정리족/출족에 있지만 강의(22년 기준)에서 다루지 않은 내용
- 2015 UN 새 연령 기준 (중년 66~79세) — 22년 미언급
- 운동선수 근력 증대 목적 T 투여 불법 — 22년 미언급
- 치료 연령 제한 80세 미만 — 22년 미언급
- TRT 전 간기능 검사 (이전 기출 단골) — 22년 Safety 검사 항목에 미포함
- 테스토스테론 최대 분비 시점이 "저녁"이라는 오답 선지 — **오전에 많이 분비**가 정답임을 유념

### 💡 출족 고빈도 토픽 — 오늘 강의에서 강조된 것

1. **"증상 + 혈중 T 저하" 두 가지가 동시에 필요** — 가장 자주 출제 (6회 이상)
2. **TRT 효과 판단 = 환자의 증상 및 징후** (혈중 T 수치나 PSA 수치가 아님)
3. **Safety 검사** = 간기능검사 + **PSA + Hct** — CRP, IGF-1 등은 아님
4. **채혈은 오전** (야간에 분비 → 오전에 높음 → 오전 채혈)
5. **Short-acting 먼저 투여 후 long-acting으로 전환**

### ⚡ 강의에서 처음 나온 내용 중 출제 가능성 높은 것

> 출족 작성자 코멘트: "교수님께서 별표시를 하셨으며, 새 문제를 내기 위해 별표를 하셨다"

1. **테스토스테론 감소 4가지 원인** (★ Leydig cell/LH 자극/receptor/SHBG 증가) — 별표 내용 + 체계적 분류라 MCQ로 출제 용이
2. **전립선암 징후 4가지** (★ PSAV 0.75 / PSA 밀도 0.15 / %free PSA 0.15) — 수치 묻는 문제로 출제 가능
3. **치료 목표 혈중 T = 450~600 ng/dL** (젊은 남성 middle tertile) — 새 수치 기반 MCQ 가능
4. **CV event 후 3~6개월 치료 보류** — 새 교수님 강조 포인트
5. **Hct >52% = 절대 금기** — 구체적 수치 기억 요구

## 오늘 수업 요약 암기 포인트 (5분 복습용)

1. **진단** = 증상(갱년기 증상) + 혈중 T 저하 *둘 다 필수*
2. **채혈은 오전** (T는 오전에 최고치), 300 미만 치료 가능, **230 미만 적극 고려**
3. **T 감소 원인 4가지**: Leydig cell↓ / LH 자극↓ / T receptor↓ / SHBG↑
4. **절대 금기**: 전립선암 + 남성유방암 (상대적: 심한 LUTS, sleep apnea, CHF, Hct>52%)
5. **CV event 후 3~6개월은 TRT 금지**
6. **전립선암 징후 수치**: PSAV ≥0.75/yr, PSA밀도 ≥0.15, %free PSA **<0.15**
7. **DRE + PSA** 검사: 치료 전 / 3~6개월 / 12개월
8. **초기 치료 = Short-acting 먼저** (4주 enanthate 또는 Gel) → 이후 long-acting 전환
9. **치료 목표**: 450~600 ng/dL (젊은 남성 middle tertile)
10. **TRT 효과 판단 지표 = 환자의 증상 및 징후** (T 수치 자체가 아님)
