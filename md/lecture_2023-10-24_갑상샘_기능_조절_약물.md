## 강의 파일 핵심 내용

### 1. 갑상선 호르몬(TH) 생합성 과정
- **NIS**로 혈중 iodide 능동 운반 → 갑상선 세포 내 농도 혈중의 20-50배
- **peroxidase**: iodide 산화 → thyroglobulin의 tyrosine 요오드화(organification) → coupling (MIT+DIT→T3, DIT+DIT→T4)
- endocytosis → lysosome 융합 → thiol endopeptidase로 T3/T4 유리
- **억제제**: 강심배당체, Thiocyanate, Perchlorate → NIS 억제

### 2. 저장·운반·대사
| 항목 | 수치/내용 |
|------|-----------|
| 갑상선 내 iodine | 10-20 mg, 이 중 30%가 TH와 결합 |
| 자급 가능 기간 | 50-120일 → **항갑상샘제 투여해도 즉시 분비 감소 안함** |
| 혈중 T4 : T3 | 90-95% : 5% |
| Free T4 | 전체 T4의 **0.03%** |
| Free T3 | 전체 T3의 **0.3%** |
| 반감기 | T4: 6-8일 (기능항진증 3-4일↓, 기능저하증 9-10일↑) |
| T3 생성 | 혈중 T3의 **80%**가 말초조직(주로 간)에서 5'-deiodinase로 T4에서 변환 |

- TBG 결합 → 생물학적 불활성 + 반감기 연장
- **5'-deiodinase 억제제**: 산화제, **PTU**, glucocorticoid, fatty acid
- T4 바깥고리(5') 탈요오드화 → T3 / 안쪽고리(5) 탈요오드화 → rT3(비활성)

### 3. 생리학적·약리학적 작용
- **에너지/발열**: 뇌·생식선·비장 **제외** 대부분 조직에서 기초대사율 증가
- **심혈관**: 심박수·심근수축력·심박출량 증가; T3 → α-MHC↑, β-MHC↓; 심근 β-아드레날린 수용체 발현 증가 → catecholamine 반응성 증가
- **성장/발달**: 출생 후 **6개월** TH 부족 → 비가역적 지능장애 + 신경계 형태 이상 (neuronal migration 장애, synaptogenesis 감소); 생 후 첫 **2주 내** 치료 시 예방 가능; myelin basic protein 유전자 발현 촉진
- **대사**: CYP7A1 자극 → 콜레스테롤→담즙산 변환↑ → 혈중 콜레스테롤↓ → **갑상선 기능저하증에서 고콜레스테롤혈증**; 간 LDL 수용체 발현 증가

### 4. 갑상선 호르몬 제제

| 제제 | 특징 |
|------|------|
| **Levothyroxine (L-T4)** | 안전성·균일성 우수, 흡수 불완전(80%), **공복 투여** 원칙, 장기치료 1차 선택 |
| **Liothyronine (L-T3)** | 효력 3-4배 강하고 신속, **Myxedema coma·응급 시** 사용, 혈중 농도 추적 어려워 장기투여 부적합, 심장독성 위험 |
| **L-Trix (Comthyroid)** | T4:T3 = **4:1** 혼합 |

#### Levothyroxine 용량 증가 필요한 경우
- **흡수 감소**: Aluminum antacid, PPI, sucralfate, bile acid sequestrants, Ca carbonate, iron salts, raloxifene, soy products, food
- **대사 증가 (CYP3A4 유도)**: Rifampin, Carbamazepine, Phenytoin, Sertraline
- **T4→T3 변환 억제**: Amiodarone
- **기전 불명/복합**: Estrogen, 임신, Lovastatin, Simvastatin, Tyr kinase inhibitors

#### 용량 감소 필요: 고령(>65세), 여성에서 Androgen 치료
#### Free T4 변화 없이 TSH만 감소: **Metformin**

### 5. 항갑상샘제 및 갑상샘 억제제

#### ① Thioamide계 (PTU, carbimazole, methimazole)
- **공통 기전**: peroxidase 억제 → thyroglobulin tyrosine 요오드화 억제 + coupling 억제
- **PTU만 추가**: 말초에서 T4→T3 탈요오드화(5'-deiodinase) 억제 → **thyroid storm·심한 갑상샘 항진증에서 PTU 선택 근거**
- **Methimazole**: Graves disease 1차 약물, 작용 지속시간이 상대적으로 김; methimazole은 T4→T3 변환 억제 못함
- **Pharmacokinetics**: PTU 혈장 단백 결합 75%(큼), Methimazole 반감기 4-6시간(더 긺), Methimazole 태반 통과↑·모유 분비↑
- **부작용**: Agranulocytosis(reversible), sore throat + fever, 태반 통과(임신 중 금기), 수유 중 금기

#### ② Ionic inhibitors
- **Thiocyanate(SCN⁻)**: 요오드 유기화(organification) 억제; 식물성 glycoside, 양배추, **담배** → 혈중 농도 증가 → subclinical hypothyroidism 악화
- **Perchlorate(ClO₄⁻)**: NIS를 경쟁적으로 억제, thiocyanate보다 **10배 강함**, 과량 → fatal aplastic anemia
- **Lithium**: T4, T3 분비 억제 → mania 치료 중 hypothyroidism 유발

#### ③ 고농도 Iodide 제제
- **Wolff-Chaikoff effect**: >6mg/d 고용량 → iodide 이동 억제 → TH 합성 억제 → 시간이 지나면 escape 발생
- thyroglobulin 단백질 분해 억제 → TH 유리 억제 → **severe thyrotoxicosis에 효과적**
- 효과: striking and rapid, 갑상선 혈관분포 감소·조직 단단해짐·세포 작아짐
- **임상 응용**: 갑상선 절제술 **전 예비 치료**, 갑상선 중독 발작 시 propranolol + 항갑상선 약물과 **병용**
- **부작용**: angioedema, laryngeal edema, iodism

#### ④ 방사능 Iodine
| 동위원소 | 반감기 | 용도 |
|----------|--------|------|
| **¹³¹I** | 8일 | 갑상선 기능 항진증 치료, 갑상선암(여포암) 전이 치료 |
| **¹²³I** | 13시간 | 갑상선 기능 **진단·갑상선 주사(scan)** |
| **¹²⁴I** | — | **PET/CT** scanning |

- ¹³¹I 부작용: 지연성 갑상선 기능저하증, radiation thyroiditis, 임신 중 태아 갑상선 파괴(임신 3-4개월 이후 금기)

### 6. 특수 임상 문제
- **점액수종 혼수(Myxedema coma)**: IV T3 투여(Liothyronine)
- **임신 중 갑상선 중독증**: 방사성 요오드 **금기**, 임신 초기 → PTU, 임신 중기 이후 → Methimazole으로 전환(PTU 간독성 회피)
- **신생아 Graves**: 태반 통과한 TSH-R 항체에 의해 발생

## 정리족과의 비교

### ✅ 정리족과 일치하는 내용

- TH 생합성 전 과정 (NIS, peroxidase, iodination, coupling, endocytosis, proteolysis)
- 저장·분비: 50-120일 자급 → 항갑상샘제 즉각 효과 없음 `[PP]`
- 운반: TBG 주요 운반체, free T4 0.03% / free T3 0.3% `[PPP]`
- 말초 5'-deiodinase로 T3 80% 생성 `[PPP][2016出]`
- TBG 결합에 영향 미치는 인자 표(Estrogen → 증가 / Glucocorticoid·Androgen·Salicylate → 감소) `[2021,20,19,18出]`
- 생리적 작용: 칼로리 생산(뇌·생식선·비장 제외), 심혈관, 성장발달
- 출생 후 6개월 TH 부족 → 비가역적 지능장애 `[2016,15出]`
- 갑상선 호르몬 제제(L-T4, L-T3, L-Trix) 및 임상 응용
- Thioamide계 약물 기전·부작용, Ionic inhibitors, Iodide 제제, 방사능 iodine 전반
- 갑상샘 기능저하증·항진증 특수 문제들

### 🆕 강의에만 있는 새 내용 (중요!)

1. **Levothyroxine 용량에 영향 미치는 구체적 약물 목록** (정리족에 없음)
   - CYP3A4 유도제: **Rifampin, Carbamazepine, Phenytoin, Sertraline**
   - T4→T3 변환 억제: **Amiodarone** → 용량 증가 필요
   - TSH만 감소(free T4 변화 없음): **Metformin**
2. **Methimazole이 Graves disease의 drug of choice**임을 강의록에 명시 (정리족은 PTU 중심 설명)
3. **Thyroid storm 시 PTU를 다른 약보다 선호하는 rationale** (T4→T3 변환 억제 효과 때문임을 명시)
4. **¹²⁴I → PET/CT**에 사용됨이 강의에서 추가
5. T4 흡수율 **80%** 수치가 강의에서 명시(정리족은 "40-70%"라고 다르게 기재됨 ⚠️)

### ⚠️ 정리족에 있지만 강의에서 다루지 않은 내용

- 갑상선 무게 30-60g, 인체 최대 내분비샘
- T3 receptor affinity가 T4보다 10배 높음 / 작용 duration은 T4가 T3보다 긺
- TRH 분비 조절 세부 (저온 → TRH↑, 스트레스 → TRH↓) `[2018出]` — 강의에는 표만 언급
- **Jod-Basedow effect** (지속적 고용량 iodine → 오히려 TH 생성 촉진) — 강의록에는 "escape"만 언급
- 갑상선 호르몬의 세포막 수용체를 통한 포도당·아미노산 이동 촉진 기전 상세
- PTU vs MMI pharmacokinetics 표 상세(정리족에 더 자세히 정리됨): PTU 단백결합 75%, MMI volume of distribution 더 큼

### 💡 출족 고빈도 토픽 — 오늘 강의에서 강조된 것

1. **L-T3 vs L-T4 구분** — myxedema coma 응급 = L-T3, 장기치료 = L-T4 (`2014~2021 매년 반복`)
2. **PTU의 이중 기전** — peroxidase 억제 **AND** deiodinase 억제 (`2015~2022 반복`)
3. **TBG 결합 증가/감소 인자 표** — Estrogen(증가), Glucocorticoid/Androgen/Salicylate(감소) (`매년 1문제`)
4. **출생 후 "6개월"(6주·6일 아님) 비가역적** — "가역적"으로 함정 자주 제시 (`2012~2015 반복`)
5. **칼로리 생산 없는 3곳**: 뇌·생식선·비장 — "뇌와 생식선에서는 없다"(비장 누락)으로 함정 제시

### ⚡ 강의에서 처음 나온 내용 중 출제 가능성 높은 것

1. **Amiodarone → T4→T3 변환 억제 → Levothyroxine 용량 증가 필요** (CYP3A4 유도제들과 묶여 출제 예상)
2. **Metformin → free T4 변화 없이 TSH만 감소** (독특한 기전이라 단독 출제 가능)
3. **Methimazole = Graves disease drug of choice**, PTU는 thyroid storm 시 선호 이유 (임상 응용 문항)
4. **CYP3A4 유도제 (Rifampin, Carbamazepine, Phenytoin) → Levothyroxine 대사 증가** (약물 상호작용 문항)
5. **¹²⁴I = PET/CT 용도** (¹²³I·¹³¹I와 구분해서 출제 가능)
