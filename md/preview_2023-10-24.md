## 📋 핵심 개념 요약 (정리족)

## 1교시 갑상샘 기능 조절약물 (김치대)

- **핵심 키워드**: TH 합성경로, TBG, T3/T4 전환, Thionamide, 방사성 요오드
- **핵심 개념 요약**:
  - TH 합성: iodide uptake → oxidation → organification(MIT/DIT) → coupling(MIT+DIT=T3, DIT+DIT=T4) → proteolysis & release
  - 혈중 T4 90~95%, T3 5%; 대부분 TBG와 결합(비활성), free form만 활성
  - 말초(주로 간)에서 5'-deiodinase가 T4→T3 변환(혈중 T3의 80%); rT3는 비활성
  - Levothyroxine(T4): 기본 보충제 / Liothyronine(T3): 응급(myxedema coma)에 IV 투여
  - Thionamide(PTU, methimazole): peroxidase 억제 → 합성 차단; PTU만 T4→T3 전환도 억제
- **교수 강조 포인트**:
  - 저장분이 많아 항갑상샘제 투여 후 즉시 호르몬 감소 안 됨
  - TBG 증가(estrogen, 임신) → free T4↓ → TSH↑
  - 갑상선 기능저하 시 고콜레스테롤혈증, GH 분비 감소
  - 임신 중: PTU 가능, methimazole 금기; 방사성 요오드(131I) 임신 중 절대 금기

## 2교시 갑상선질환 외과치료 (이진춘)

- **핵심 키워드**: 엽절제술 vs 전절제술 적응증, 합병증, Graves' 수술 적응증, 갑상선암 종류
- **핵심 개념 요약**:
  - 엽절제술 적응증: <2cm, 단일병소, 한쪽 엽 국한, 갑상선 외 침윤 없음, 림프절·원격전이 없음
  - 전절제술 적응증: 원발암 >4cm, 양측 결절, 갑상선 외 침윤, 림프절·원격전이, 방사선 과거력, 가족력, 45세 이상
  - 주요 합병증: ①되돌이 신경 손상(쉰 목소리) ②부갑상선 손상(저칼슘혈증, 손발저림) ③**출혈**(응급수술의 가장 큰 원인 — 기도 압박 → 호흡곤란)
  - 갑상선암 종류: 유두암(가장 흔함, 중앙경부림프절 절제) / 여포암(원격전이 잦음) / 수질암(가족력 중요, 전절제) / 역형성암(예후 최악)
  - Graves' 절대 적응증: 악성 의심, ATD 조절 안 되는 임신부, 6~12개월 내 임신 계획, 압박 증상, ATD 재발, 방사성 요오드 거부
- **교수 강조 포인트**:
  - Graves' 상대 적응증: large goiter, **severe ophthalmopathy**(절대 적응증 아님), poor compliance, children
  - 출혈 자체보다 **기도 압박으로 인한 호흡곤란**이 응급수술 이유
  - Level VI lymph node: 유두암에서 50% 이상 전이, 초음파로 발견 어려움

## 3교시 성선기능조절 약물 (배순식/이동원)

- **핵심 키워드**: SERM, Aromatase inhibitor, Progesterone receptor, 피임, 조기분만
- **핵심 개념 요약**:
  - Estrogen 합성: LH → Theca cell(androgen) → FSH/aromatase → Granulosa cell(estrogen); 두 세포 협동
  - SERM: 세포 종류에 따라 agonist/antagonist 가능 — Tamoxifen(유방 길항·자궁 작용), Raloxifene(뼈만 작용, 골다공증)
  - Aromatase inhibitor(anastrozole, letrozole): tamoxifen 내성 유방암 치료
  - 피임제: 복합 경구(ethinylestradiol+progestin) / 응급 피임: ulipristal(120h 이내), levonorgestrel(72h 이내)
  - Mifepristone(600mg)+misoprostol(48h 후): 치료적 유산 (마지막 월경 후 49일 이내)
- **교수 강조 포인트**:
  - GnRH analogs(leuprolide, goserelin): 지속 투여 시 receptor 탈감작 → LH/FSH↓ → 전립선암·자궁내막증 치료
  - 5α-reductase inhibitor(finasteride): BPH, 탈모 치료; 임신 여성 주의
  - PDE5 inhibitor(sildenafil): cGMP↑ → 음경평활근 이완 → 발기

## 4교시 성호르몬 작용·평가 (박현준)

- **핵심 키워드**: Testosterone 분비·대사, SHBG, DHT, 성호르몬 평가 검사
- **핵심 개념 요약**:
  - 테스토스테론: 95% 고환(Leydig cell)에서 분비, 대부분 SHBG(60%)·알부민(38%) 결합; free(2%)만 활성
  - T 대사 3경로: ①지방세포 aromatase → E2 ②전립선 5α-reductase → DHT(더 강력) ③정자 생성
  - 일중 변동: **오전에 최고** → 반드시 오전에 측정
  - 40대 이후 서서히 감소; 비만·고지혈증·만성질환 환자에서 T 생성 감소
  - 동적 검사: hCG 자극(고환 기능 평가), 클로미펜 자극(뇌하수체·시상하부 평가), GnRH 자극(시상하부 vs 뇌하수체 감별)
- **교수 강조 포인트**:
  - 성호르몬 평가: 외성기 형태·고환 크기 + serum T, FSH, LH (오전 측정)
  - Hypogonadism 분류: Hypergonadotropic(고환 문제) vs Hypogonadotropic(뇌하수체/시상하부 문제)

## 5교시 남성 갱년기 (김현우)

- **핵심 키워드**: TDS 진단, 혈중 T 기준치, TRT 금기, 전립선 암 징후, 치료제 종류
- **핵심 개념 요약**:
  - 정의: 노화 관련 테스토스테론 저하 + 관련 증상(LOH/TDS)
  - 진단: 증상 확인 + **혈중 T 오전 측정**: 300ng/dl 미만(치료 가능), 230ng/dl 미만(적극 치료)
  - TRT 금기: 전립선암·남성 유방암(절대 금기), 적혈구 과다증(Hct>52%), 치료 안 된 수면 무호흡·CHF; **CV event 3~6개월 이내 시 보류**
  - 치료제: 4주 근주(T. enanthate, short-acting) → 부작용 확인 후 12주 근주(T. undecanoate, long-acting)로 전환
  - 치료 전·후 3~6개월·12개월: DRE + PSA 확인
- **교수 강조 포인트**:
  - 전립선암 징후: DRE 결절 / PSA 속도 ≥0.75ng/ml/년 / PSA 밀도 ≥0.15 / %free PSA <0.15
  - 치료 목표 T: 450~600ng/dl (젊은 남성 low~mid level)
  - 나이 자체는 TRT 금기 아님

## 6교시 갑상선 영상의학 (김학진)

- **핵심 키워드**: T1/T2 영상 구분, dynamic study, macroadenoma, craniopharyngioma, Rathke cleft cyst
- **핵심 개념 요약**:
  - T1: CSF 검정, 물 많으면 검정 / T2: CSF 흰색, 물 많으면 흰색
  - 빠른 혈류(internal carotid a.): T1·T2 모두 검정; MRI 조영제(Gadolinium) 줘도 검정 유지
  - Dynamic study: 조영제 주입 후 60~90초에 정상 뇌하수체는 하얗게, microadenoma는 검게(조영 지연) → 소병변 발견
  - Macroadenoma(>1cm): 조영 후 강하게·불균일하게 증강(snowman appearance); hemorrhage 동반 시 T1 고신호
  - Craniopharyngioma: calcification + solid&cystic suprasellar mass + T1 고신호(단백↑)
  - Rathke cleft cyst: 조영 안 되는 정중선 낭종 + **intracystic nodule** + **Claw sign**(정상 뇌하수체가 눌려 조영)
- **교수 강조 포인트**:
  - Fluid-fluid level → 100% hematoma
  - T1 고신호 원인: hemorrhage, 고단백(RCC·craniopharyngioma), 지방
  - Microadenoma: off-midline 위치, dynamic study로만 발견 가능

## [7교시] 갑상선 영상의학 — 김학진

🔥 **출 빈도**: ★★★★★ — 총 25문항+ 확인 (2009~2021, 매년 출제)

- **해부학 명칭 식별** (coronal T1 조영 영상): 2012, 2013, 2014, 2015, 2016, 2017, 2018, 2019, 2020, 2021 = **10회+** (매년 1문항 고정)

- **Craniopharyngioma 특징** (calcification + suprasellar cystic&solid mass): 2010, 2017, 2019, 2020 = **4회**

> **핵심 원포인트**: 해부학 명칭 — **lateral ventricle / optic chiasm / pituitary stalk / cavernous sinus / ICA** 5개 위치 반드시 숙지. 사진 문제는 "suprasellar 위치 + calcification = craniopharyngioma", "claw sign + 조영증강 없음 = Rathke cleft cyst", "sellar solid + 조영증강 = macroadenoma" 패턴으로 구분.
