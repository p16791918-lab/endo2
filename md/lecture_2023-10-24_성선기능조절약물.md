## 강의 파일 핵심 내용
*(정리족 작성자 코멘트: 강의록 전부를 설명하시는 교수님 / 시험은 거의 다 약물 관련)*

### 1. Steroidogenesis (기초 경로)
- Cholesterol → Pregnenolone → Progesterone → Glucocorticoid(cortisol) / Androgen → **Aromatase**에 의해 → **Estrogen**
- Aromatase 유전자는 X염색체에 없음

### 2. Estrogen Synthesis — **Two-cell, Two-gonadotropin Theory** ★
| 세포 | 호르몬 자극 | 산물 |
|---|---|---|
| Theca cell | LH | Androgen 합성 |
| Granulosa cell | FSH (aromatase 유도) | Androgen → Estrogen 전환 |

### 3. 성호르몬 생리 작용
- **Estrogen**: 2차 성징, 파골세포 억제 → 골형성↑, 성장판 폐쇄, TG↑/LDL↓/HDL↑
- **Progesterone**: GnRH pulsatile frequency↓ → LH/FSH↓ → 배란억제 → **피임 기전**

### 4. SERM (Selective Estrogen Receptor Modulator) ★★★
| 약물 | 유방 | 자궁내막 | 뼈 | 주요 용도 |
|---|---|---|---|---|
| **Tamoxifen** | Antagonist | **Agonist** (부작용!) | Antagonist | ER+ 유방암 1차 |
| **Toremifene** | Antagonist | Agonist | Antagonist | ER+ 유방암 |
| **Raloxifene** | Antagonist | Antagonist | **Agonist** | 폐경 후 골다공증 |
| **Fulvestrant** | Antagonist | Antagonist | Antagonist | Tamoxifen 내성 유방암 2차 |
| **Clomiphene** | Antagonist | Antagonist | - | **불임 치료** (LH/FSH↑→배란↑) |

- 기전: epigenetic regulation — agonist시 SRC1/p300(histone acetylation→chromatin loose), antagonist시 HDAC/NCoR(deacetylation→tight packing)

### 5. Aromatase Inhibitor ★
| 종류 | 약물 |
|---|---|
| Steroidal (비가역) | Formestane, **Exemestane** |
| Non-steroidal (가역) | **Anastrozole, Letrozole**, Vorozole |

- 효과: Estrogen↓, Androgen↑
- 용도: Breast cancer (Tamoxifen 내성 시 2nd choice), **불임 치료** (clomiphene 2nd choice)

### 6. Progesterone Receptor Regulators ★★★
| 약물 | 분류 | 기전 | 용량/시간 | 용도 |
|---|---|---|---|---|
| **Mifepristone** | PR antagonist | PR degradation → hCG↓→Prog↓ + 자궁수축 | 600mg, 마지막 월경 **<49일** | 치료적 유산 |
| Misoprostol | PGE1 | 자궁수축 | Mifepristone 48hr 후 400mg | 태아 배출 |
| **Ulipristal** | PR partial agonist | GnRH 억제, LH surge 이후에도 차단 가능 | **120h(5일) 이내** | 응급 피임 |
| Levonorgestrel | Progestin | 배란억제 | **72h(3일) 이내** | 응급 피임 |

### 7. 불임 치료 약물 (Female, 1st→2nd→3rd)
1. **Clomiphene** (anti-estrogen: neg. feedback 차단 → FSH/LH↑)
2. **Aromatase inhibitors** (letrozole 등: estrogen 합성↓ → neg. feedback 차단, endometriosis 환자 선호)
3. **Gonadotropins** (FSH, LH 직접 투여)

### 8. 남성 호르몬 조절 약물
- **GnRH analogs** (leuprolide, goserelin): 지속 투여 → receptor desensitization → LH/FSH↓
  - 용도: 전이성 전립선암, Endometriosis, 유방암
- **AR antagonists** (flutamide, bicalutamide, nilutamide): 안드로겐 수용체 직접 차단 → 전이성 전립선암
- **5α-reductase inhibitors** (finasteride, dutasteride): DHT↓ → BPH, **탈모** 치료
  - DHT: 머리 모낭 퇴화 + 체모 모낭 발달 (type 1 지속발현, type 2 나이들면서↑)

### 9. 발기부전 치료
- 경로: 부교감신경 → NO → cGMP↑ → PKG → Ca²+↓ → smooth muscle 이완 → 발기
- **PDE5 inhibitors** (sildenafil, tadalafil, eudenafil): cGMP 분해 억제

### 10. 조기분만 억제/촉진 약물
| 효과 | 기전 | 약물 |
|---|---|---|
| **자궁 이완** (조기분만 억제) | Ca²+ channel 억제 | Nifedipine, MgSO₄ |
| | β2 agonist | Ritodrine, Terbutaline |
| | Oxytocin receptor 억제 | **Atosiban** |
| **자궁 수축** (분만 촉진) | α1 agonist | **Ergonovine**, Methylergonovine |
| | Oxytocin 직접 | Oxytocin |

## 정리족과의 비교

### ✅ 정리족과 일치하는 내용
- Steroidogenesis 전체 경로 (Cholesterol → Estrogen)
- Two-cell, Two-gonadotropin theory (Theca+Granulosa)
- SERM 분류 및 각 조직별 agonist/antagonist 효과
- Tamoxifen: 유방암 1차, 자궁내막에서 agonist 부작용
- Raloxifene: 폐경 후 골다공증, 뼈에서만 agonist
- Fulvestrant: Tamoxifen 내성 유방암 2차
- Aromatase inhibitor 종류 및 분류
- Mifepristone 600mg + Misoprostol 48hr 조합, <49일 조건
- Ulipristal 120h, Levonorgestrel 72h 구분
- 불임 치료 순서 (clomiphene → aromatase inhibitor → gonadotropin)
- GnRH analogs desensitization 기전
- 5α-reductase inhibitors (finasteride → DHT↓ → BPH/탈모)
- PDE5 inhibitors (sildenafil 등)
- 조기분만 약물 전체 목록

### 🆕 강의에만 있는 새 내용 (중요!)
- **Ulipristal의 핵심 차별점**: LH surge **이후에 사용해도** surge shutdown 가능 — levonorgestrel과의 핵심 차이
- **Mifepristone의 이중 효과**: PR receptor degradation(직접 antagonism) + hCG↓→Progesterone↓(간접 효과) — 두 가지 기전 강조
- **SERM epigenetic mechanism**: SRC1/p300(HAT)에 의한 histone acetylation vs HDAC/NCoR에 의한 deacetylation — 세포 타입별 차이 원인
- **5α-reductase type 1/2 발현 패턴**: type 2는 피부/두피에서 소아기 이후 소실, type 1은 지속 발현 → 나이들수록 DHT 효과 증가
- **Clomiphene 작용기전 정밀화**: 약한 estrogen 작용으로 ER에 결합하여 강한 estradiol 결합을 경쟁적으로 방해 → 시상하부 negative feedback 차단

### ⚠️ 정리족에 있지만 강의에서 다루지 않은 내용
- **Erectile dysfunction 파트**: 정리족 기록 "이건 다 아시죠"라며 넘어가셨음 (2022 기준)
- **조기분만 약물 파트**: "이번 시간에는 다루지 않은 내용" 명시 — 출족에는 출제됨(2020)
- Estrogen의 혈관 보호 효과 세부 내용
- Regulation of metabolism (bone, lipid) 세부 그림 설명

## 출족 관점: 시험 출제 가능성

### 🔥 이번 강의 내용 중 기출 있는 토픽 (연도 및 문제 유형 포함)

| 연도 | 내용 | 답 |
|---|---|---|
| **2021-1** | Mifepristone(A) + Misoprostol(B) 조합 주관식 | A=mifepristone, B=misoprostol |
| **2021-1** | 마지막 생리 6주 지난 잠재적 임신 종료 약물 | Lilopristone (pristone계열 = PR antagonist) |
| **2021-1** | 4일 전 원치 않은 관계 응급 피임 | Ulipristal (120h 이내) |
| **2020** | 자궁근 수축 유도 약물 | Ergonovine |
| **2020** | 탈모 + BPH 치료 약물 | Finasteride |
| **2019** | 유방암 약물X 조직별 효과 (breast/osteocyte=antagonist, endometrium=agonist) | Tamoxifen |
| **2019** | 1개월 전 원치 않은 관계, 임신 종료 | Mifepristone (<49일) |
| **2018** | 폐경 후 골다공증 약물 | Raloxifene |
| **2018** | 4일 전 원치 않은 관계, 피임 | Ulipristal |

**패턴**: SERM 토픽(18, 19, 21-2) + 피임/유산 약물(18, 19, 21-1, 21-2) + 탈모·수축약(20) — 매년 1~2문제 고정 출제

### 💡 출족 고빈도 토픽 — 오늘 강의에서 강조된 것
1. **Tamoxifen vs Raloxifene 구분** ★★★ — 자궁내막 agonist 여부가 핵심 변별 포인트
2. **Mifepristone vs Ulipristal 구분** ★★★ — 시간(49일 vs 120h) + 기전(PR antagonist vs partial agonist) + 착상 전후 효과
3. **Clomiphene 기전** ★★ — antiestrogen으로 neg. feedback 차단 → FSH/LH↑ → 배란 촉진 → 불임 치료
4. **Finasteride** ★★ — 5α-reductase 억제, DHT↓, BPH + 탈모 둘 다 치료
5. **Ergonovine** ★★ — α1 receptor agonist → 자궁수축 → 분만 촉진 (atosiban/ritodrine/nifedipine은 이완)

### ⚡ 강의에서 처음 나온 내용 중 출제 가능성 높은 것
1. **Ulipristal의 LH surge 이후 효과** — "surge 이후에도 사용 가능 = ovulation 억제하는 가장 강한 약물" → 선지로 출제 가능성 높음
2. **Aromatase inhibitor 계열 구분** — steroidal(formestane/exemestane) vs non-steroidal(anastrozole/letrozole) → 신약 문제로 출제 예고됨 (출족 작성자: "2030 이전 출제 예상")
3. **불임 치료 약물 순서** — clomiphene → aromatase inhibitor (endometriosis 동반 시 선호) → gonadotropin 직접투여
4. **GnRH analog 역설적 억제** — pulsatile 필요한데 continuous 투여 시 receptor desensitization → FSH/LH↓ → 이 역설 자체가 문제로 출제 가능

## 오늘 수업 요약 암기 포인트
*(시험 직전 5분 복습용)*

1. **SERM 핵심 구분**: Tamoxifen = 유방(−)/뼈(−)/자궁(+✗부작용) | Raloxifene = 유방(−)/뼈(+)/자궁(−) | Fulvestrant = 모두(−, tamoxifen 내성 후)
2. **피임 시간 구분**: Levonorgestrel ≤72h | **Ulipristal ≤120h** (surge 이후도 OK = 최강) | Mifepristone = 이미 임신(<49일), 600mg
3. **유산 콤보**: Mifepristone 600mg → 48h → Misoprostol(PGE1) 400mg → 자궁수축→태아배출
4. **불임 치료 순서**: Clomiphene (1st) → Aromatase inhibitor (2nd, endometriosis有) → Gonadotropin (3rd)
5. **탈모 = Finasteride** (5α-reductase 억제 → DHT↓) = BPH도 치료 가능
6. **자궁수축 = Ergonovine/Methylergonovine** (α1 agonist) / 이완 = Atosiban(oxytocin拮抗) + Ritodrine/Terbutaline(β2) + Nifedipine/MgSO₄(Ca차단)
7. **GnRH analog (leuprolide, goserelin)** = continuous 투여 → desensitization → LH/FSH↓ → 전립선암/자궁내막증 치료
8. **AR antagonist (flutamide)** = 전립선암 | **5α-reductase inhibitor (finasteride)** = BPH/탈모
9. **Clomiphene = antiestrogen** → ER 결합 → estradiol의 neg. feedback 차단 → FSH/LH↑ → 배란↑ → 불임
10. **Two-cell theory** = LH→Theca→Androgen / FSH→Granulosa→Aromatase→Estrogen (두 세포 협동)
